# 数据与接口交接

仅在开发加载器、训练、评估、时间映射或专项推理时读取。本文件记录已核查的数据结构，实际文件若发生变化，以当前文件和题目为准，记录差异，不静默猜测。

## 数据分工

| 附件 | 用途 | 范围 |
|---|---|---|
| 1 | 问题1自行提取与时间对齐 | 100条原始视频及label-100.xlsx |
| 2 | 问题2、3模型训练与验证 | 每版4850条；train 3395、valid 728、test 727 |
| 3 | 问题2最终专项推理 | 对齐与未对齐各30条，无标签 |
| 4 | 问题3最终预测与解释 | 每版20条特征与视频，无标签；两版视频为同20条 |

问题1方法可以被后两问复用，其100条自生成特征不自行追加到后两问训练集。附件2训练集学习参数，验证集选择结构、超参数与阈值；保留test作最终独立评估是项目建议。附件3、4不参与训练、调参或阈值选择。不得引入额外情感数据集参与训练、优化或结果统计；预训练工具的使用遵循题目并记录来源、版本及配置。

## 张量与字段差异

附件2顶层按train/valid/test组织，访问方式为 `data[split][field][index]`。

| 版本 | 单样本文本 | 单样本音频 | 单样本视觉 |
|---|---|---|---|
| 对齐 | 50×768 | 50×74 | 50×35 |
| 未对齐 | 50×768 | 500×74 | 500×35 |

- text为预计算文本特征；text_bert为3×50的词元编号、注意力掩码、分段编号，需对应编码器处理；不是第四模态。
- 附件2实际没有annotations字段，不能因题目字段表列出它就直接索引；文字标签可从配套表核对。
- 附件2未对齐版有audio_lengths和vision_lengths。
- 附件3各文件顶层为test。对齐版只有text_bert、audio、vision，含大小为1的批次维度；未对齐版只有raw_text、audio、vision，无有效长度字段。
- 附件4单文件直接为样本字段字典，没有批次维度；含id、raw_text、text、text_bert、audio、vision，未对齐版另有有效长度。
- 分类映射：0负向、1中性、2正向；强度范围[-3,3]，零为中性。

问题2若使用text_bert，需核实词表、特殊词元与编码器兼容性，并确保训练与专项输入走一致编码流程；不能假定自己重新编码的向量与附件2已有text一致。未对齐版raw_text重新编码时，还应核查是否恢复了原本希望模拟缺失的文本信息，不能假定两版缺失设置等价。

## 掩码与时间

- 填充、原始无效位置和人工连续缺失是不同状态；全零行不能单独证明属于人工缺失。
- 缺失模拟作用于有效区间，记录模态、起点、持续长度或比例及随机种子。
- 不把特征位置直接换算成秒数。时间映射注明来源、截断、填充、词元与文本对应、时间精度和失败条件。
- 音频74维按题目作为输入维度，不臆测每一维的物理意义。

## 交接最小契约

接口说明放维护者的requirements或对应模块说明中，公共文档链接至该单一来源。

| 项目 | 需要说明 |
|---|---|
| 样本身份 | 编号生成及与文件名、视频的关联规则 |
| 输入输出 | 字段、维度、数据类型、批次维度与标签映射 |
| 文本 | 编码器、词表、版本、冻结或微调方式 |
| 掩码 | 有效、填充、缺失的定义及传播方式 |
| 时间 | 单位、区间边界、映射来源与精度 |
| 运行 | 配置、入口、所需环境和最小样例 |
| 兼容性 | 受影响的调用方及已验证的路径 |

评估共同使用Accuracy、F1、MAE、皮尔逊相关系数，明确F1平均方式、无效样本与常量预测的处理。报告不同实验时保持指标口径一致。

## 最终结果

附件3输出所选版本30条预测，附件4输出20条预测与解释。CSV字段方案属于项目约定，提交前核对最新题目补充格式，不能宣称自拟字段为官方固定格式。

题目要求提交附件总大小不超过50MB；打包时包含必要自生成特征、代码、配置、参数、结果及复现说明，不把全部原始数据和重复缓存打包。按题目检查身份信息。模型性能与文件大小应分别验证，不能只因压缩成功就认为可复现。
