# 多模态情感预测项目：三天模块分工与论文写作计划

## 1. 计划前提与目标

- 总工期为3天，按每人每天约12小时有效工作时间安排，休息另计。文中的小时均为当天累计有效工作时间。
- 问题1已有代码跑通，不重新开发；先确认是否覆盖全部100条样本，以及输出是否满足题目要求，再补齐结果与论文。
- 问题2、3并行推进，共用数据读取、基础融合与评估代码，各自维护专项策略、配置和模型权重。
- 写论文属于正式工期：第1天形成方法正文，第2天完成全文初稿，第3天完成最终结果更新、统稿和提交检查。
- 优先确保题目要求全部交付，再开展有限的性能优化。第2天结束后不增加新的模型路线。

## 2. 人员角色

| 人员 | 研究方向 | 主要职责 | 写作与协作职责 |
|---|---|---|---|
| A | 计算机视觉 | 问题1成果核查、时间映射、视频证据定位 | 撰写特征与对齐内容，负责公共章节及全文统稿 |
| B | 多模态图像处理 | 统一数据接口、融合基线、模态贡献与局部解释 | 撰写融合与解释内容，为C提供共享模型接口 |
| C | 智能优化算法 | 局部缺失建模、鲁棒训练、有限参数搜索、统一评估 | 撰写鲁棒性与实验分析内容，管理实验记录及提交包 |

若问题1现有代码由其他组员完成，原负责人向A交接代码、配置、运行环境和输出结果，不重复实现。

## 3. 数据使用边界

| 数据 | 使用模块 | 用途与约束 |
|---|---|---|
| 附件1：100条原始视频及转写、标签 | M2、M3 | 问题1特征提取、时间对齐与结果展示；不得擅自增删或替换样本及标签 |
| 附件2：标准化特征 | M1、M4、M5、M6、M7 | 问题2、3使用train训练、valid选择结构和参数；建议保留test用于最终独立评估 |
| 附件3：局部缺失专项样本 | M1、M5 | 所选版本30条样本的最终推理，不用于训练或调参 |
| 附件4：完整模态专项样本与视频 | M1、M3、M6 | 所选版本20条样本的最终预测、解释及视频证据核查，不用于训练或调参 |

问题1的方法和代码可以复用，但其100条自生成特征不替代附件2的既定训练数据，也不自行加入问题2、3训练集。

## 4. 模块分工与交付标准

### M1：数据读取与统一接口

- 负责人：B；C协助核对附件3。
- 工作：统一附件2、3、4的读取方式、批次维度、文本输入、标签映射、填充及缺失掩码；跑通专项数据读取。
- 交付：共用数据加载器、字段说明、可运行的读取示例。
- 验收：训练数据与两类专项数据均能转换为各自模型所需输入；编号可追溯，标签映射一致。
- 截止：第1天前4小时。

### M2：问题1成果核查与补齐

- 负责人：A。
- 工作：检查已有代码及全部100条样本输出；补齐维度、有效长度、填充规则、异常处理与日志记录。
- 交付：100条特征文件、全量结果汇总表、处理记录和复现说明。
- 验收：样本与特征一一对应，无遗漏；异常处理有依据，保留原始样本。
- 截止：第1天结束。

### M3：时间映射与视频证据定位

- 负责人：A；B协助定义接口。
- 工作：整理问题1典型对齐案例；为问题3建立并核查关键位置到文本、语音时段和视频帧的映射。
- 交付：对齐示例图、证据定位接口、关键帧与时间区间记录。
- 验收：展示的证据能回查原视频；不将特征序号直接当作秒数；无法精确映射时说明精度和限制。
- 截止：第2天前半天。

### M4：共用融合基线

- 负责人：B。
- 工作：实现三模态编码、融合、分类与回归输出；提供统一训练、验证和推理入口。
- 交付：可运行基线、模型接口说明、配置与基线权重。
- 验收：附件2训练与验证流程完整，指标可复现；C能够通过独立模块或配置接入缺失策略。
- 截止：第1天结束。

### M5：局部缺失与鲁棒训练

- 负责人：C。
- 工作：构造有效区间内的连续局部缺失，区分填充与缺失；实现鲁棒训练，开展有限参数搜索；分析缺失模态、位置及持续长度的影响。
- 交付：缺失生成器、鲁棒模型、实验配置、附件3全量预测CSV。
- 验收：与共用基线有可比实验；专项结果覆盖所选版本全部30条样本，不使用专项样本调参。
- 截止：第2天完成模型与主要实验，第3天前3小时锁定最终预测。

### M6：模态贡献与局部解释

- 负责人：B；A提供时间映射与视频证据。
- 工作：输出三模态作用程度、主要参考模态和局部重要位置；制作解释卡；通过遮挡重要片段等实验核查解释是否影响预测。
- 交付：解释模块、典型解释卡、局部重要性图、附件4全量预测与解释CSV。
- 验收：覆盖所选版本全部20条样本；预测、模态贡献和证据对应一致；不只凭注意力图宣称解释有效。
- 截止：第2天完成主要方法与实验，第3天前3小时锁定最终结果。

### M7：统一评估与实验管理

- 负责人：C；B提供解释实验结果。
- 工作：统一Accuracy、F1、MAE、皮尔逊相关系数的计算；明确F1平均方式；记录配置、随机种子、数据版本、权重与指标。
- 交付：评估脚本、实验记录、基线与消融表、缺失规律图。
- 验收：实验可比较，表格与实际输出一致；模型结构、参数和阈值选择只依据验证集。
- 截止：第1天建立流程，第2天完成主要实验。

### M8：论文、图表与提交

- 负责人：A统稿，三人分写；C负责提交包整理。
- 工作：模块负责人提交方法、公式、参数、图表、结果分析与局限；统一术语和编号；检查复现、匿名及体积要求。
- 交付：论文、运行说明、代码、必要配置与模型参数、自生成特征、专项结果CSV。
- 验收：正文完整回应三问，论述有实验依据；提交材料可复现，附件总大小不超过50MB。
- 截止：第2天完整初稿，第3天定稿。

## 5. 三天工期表

| 时间 | A：特征、时间映射、统稿 | B：接口、融合、解释 | C：缺失、评估、实验 |
|---|---|---|---|
| 第1天1—4小时 | 核查问题1代码及输出；建立论文模板 | 完成数据接口，跑通附件4读取 | 核对附件3；建立评估与实验配置 |
| 第1天5—8小时 | 补齐100条汇总表、对齐图及处理记录 | 完成融合基线训练与推理 | 实现连续缺失及掩码，接入基线训练 |
| 第1天9—12小时 | 写问题1方法、结果与复现说明 | 写数据表示、融合结构和目标函数；检查基线结果 | 写缺失定义、训练策略、评价与实验设置 |
| 第2天1—4小时 | 完成附件4证据时间映射，交给B | 完成模态贡献与局部解释模块 | 完成鲁棒训练和有限参数优化 |
| 第2天5—8小时 | 制作关键帧与对齐图；写公共章节 | 完成解释核查、模态对照及典型案例 | 完成缺失类型、位置、时长实验及消融 |
| 第2天9—12小时 | 合并全文，检查缺项、符号和图表 | 写解释方法、结果分析、案例和局限 | 写性能对比、缺失规律、消融和错误分析 |
| 第3天1—3小时 | 核查问题1文件与证据展示 | 固定模型，生成附件4全部最终结果 | 固定模型，生成附件3全部最终结果 |

## 6. 论文写作分工

| 论文内容 | 负责人 | 初稿时间 |
|---|---|---|
| 特征提取、时间对齐、100条汇总与对齐案例 | A | 第1天结束 |
| 数据表示、融合结构、目标函数 | B | 第1天结束 |
| 缺失定义、鲁棒训练与实验设置 | C | 第1天结束 |
| 模态贡献、局部证据、解释案例及局限 | B | 第2天结束 |
| 性能对比、缺失规律、消融及错误分析 | C | 第2天结束 |
| 问题重述、总体分析、符号说明、公共章节 | A组织，B/C补充 | 第2天结束 |
| 摘要、结论、术语与格式统一 | A组织，三人核查 | 第3天 |

第1、2天均明确预留末尾4小时用于正文与图表整理，第3天4—9小时用于最终结果更新、统稿和审阅。各负责人按章节交付文字，A负责整合，不代替其他负责人从代码中重新推导并补写方法。

每个模块交接至少包含：输入输出说明、方法和必要公式、实际参数、结果表或图、局限、复现入口。建议章节分文件编辑，由A统一合并。

## 7. 模块协作与技术约定

1. B维护数据接口和基础模型，C通过独立模块或配置加入缺失策略；避免同时修改同一核心文件。问题2、3各自保存专项模型权重。
2. A负责“特征位置对应原视频哪里”，B负责“哪些位置重要及其贡献如何计算”。两者提前统一样本编号、时间单位、区间格式和返回字段。
3. 优先使用对齐版建立完整方案。附件3对齐版只有text_bert、audio、vision，没有预计算text；第一天必须确定文本编码路线，并核实编码器与词表兼容性。问题2不能只训练依赖text的接口。
4. 训练、验证和相应专项推理保持同一特征版本。若使用未对齐版，需额外处理附件3缺少有效长度字段、仅提供raw_text等差异。
5. 不能把全部全零行直接当作人为缺失；有效区间、填充与原始无效位置必须有明确处理规则。
6. 分类标签映射统一为0=负向、1=中性、2=正向；回归强度范围为[-3,3]。所有结果使用可追溯的样本编号。
7. 结果CSV提前定义字段。附件3建议包含编号、预测极性和预测强度；附件4另含主要参考模态、各模态贡献及证据位置。该字段方案为项目内部约定，最终提交前核对是否有补充格式要求。
8. 第1天估算特征及权重体积，避免最后才发现超过50MB。仅提交题目要求的核心材料，保持可复现性。

## 8. 里程碑与范围控制

### 第1天结束

- 问题1成果覆盖检查完成，问题1正文形成完整初稿。
- 问题2、3最小训练与推理流程运行，专项输入接口经过检查。
- 融合、缺失及评估方法已有正文，实验配置有记录。

### 第2天结束

- 三问核心方法与主要实验完成，关键图表齐备。
- 全文初稿完整，不留只有标题而无内容的章节。
- 停止增加模型路线，只允许修错、补必要证据及完成最终推理。

### 第3天结束

- 100条自生成特征、附件3预测、附件4预测与解释全部齐备。
- 论文与结果文件一致，复现入口可运行。
- 完成体积、匿名、文件完整性与备份检查。

### 时间不足时的取舍

- 必须保留：全部样本输出、基线对照、核心缺失实验、解释与原素材对应、三问完整正文及复现材料。
- 优先缩减：多种特征提取器比较、大范围参数搜索、复杂新模型、多套解释方法及装饰性可视化。
- 不因追求小幅指标提升挤占统稿时间，不用未经运行验证的结果替代实验。

每天开始和结束各安排约15分钟同步，计入当天工时。同步仅确认已交付文件、接口阻塞、当天关键目标及需要调整的实验范围。
