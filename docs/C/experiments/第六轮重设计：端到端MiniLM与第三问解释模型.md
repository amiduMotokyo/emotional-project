## 1. 已核查的队友方法

主要来源：[归档说明](../../../C/outputs/q2_accuracy_screen_20260925/MINILM_README.md)、[研究记录](../../B/research/q2_accuracy_redesign.md)、[训练脚本](../../../C/scripts/finetune_q2_minilm.py)、[校准脚本](../../../C/scripts/calibrate_q2_minilm_bias.py)。本次复算证据：[archive_review.json](assets/round6_redesign/archive_review.json)；复核入口：[review_minilm_archive.py](../../../C/scripts/review_minilm_archive.py)。这些核查没有重新训练或运行ONNX模型。

实际入选结构是 **MiniLM-L6-v2 + 原Fusion**，不是GRU/Transformer七模型集成，也不是训练脚本中兼容的Temporal或Imputation分支。

- 文本从`text_bert`词元进入MiniLM，输出50×384序列；更新顶部两层，冻结其余参数。音频74维、视觉35维保持原始对齐位置，标准化只拟合附件2 train。
- 3395条train学习权重；728条valid选择epoch和后处理。每种子10轮，batch32，AdamW，编码器学习率2e-5，Fusion学习率2e-4，weight decay 0.01，梯度裁剪1。
- 连续缺失概率0.3；文本新增缺失在编码前替换为UNK，编码后对应位置不参与池化。分类为逆平方根频率加权CE，回归为0.8×SmoothL1。
- 先微调，后将编码器动态量化为int8，并按最终逐样本CPU ONNX路径重新评估。类别偏置作用于`log(p)`，负面/中性各搜索5档，正面固定0，共25个候选；三种子共享偏置。
- 最终部署候选是seed20260925、epoch3、偏置`[0.2,0,0]`。五折校准不是整个模型训练与选择的嵌套交叉验证，不能消除先前在同一valid上选epoch/模型的偏差。

### 1.2 复现中必须处理的细节

1. 22份归档文件均能与manifest对应：3个二进制文件原字节一致，18个文本经LF归一化匹配，1个CSV恢复CRLF后匹配。差异由换行表示造成；本次未改写队友文件。
2. 归档只有部署int8编码器与Fusion权重，没有完整FP32微调checkpoint。能复现部署候选，不等于能从该归档直接继续FP32训练。新实验从本地通用预训练MiniLM初始化，不把int8权重当作原始可训练权重。
3. 历史日志每epoch只有3个连续缺失验证条件；当前训练脚本评估连续和点状两种几何，共6个条件，选模键也会受影响。直接运行当前默认脚本不能宣称精确复现原历史过程。基线复现需显式固定3个连续条件；后续分支不冒充已验证候选。
4. 保存的“calibrated”逐样本JSON中，`probabilities`仍是未校准概率，`predicted_class`才应用偏置。必须先加偏置才能复核类别；新交付明确分开`raw_probabilities`与`calibrated_probabilities`，避免使用者再次校准。
5. 偏置不修改回归头，但类别改变会通过`coherent_score`改变最终强度，因此校准后MAE也需重算。新报告同时保留原始强度与最终一致性强度。
6. 当前myenv默认Transformers与huggingface-hub存在导入冲突。第三轮曾使用隔离依赖目录`C/outputs/q2_round3_env`。启动前需验证独立环境、模型加载与ONNX导出，不在运行中无记录地升级共享环境。

## 2. 如何结合前五轮，而不是重复失败组合

| 历史轮次 | 已有证据 | 本轮采用的决策 |
|---|---|---|
| 第一轮 | DE/BPSO及通道筛选没有稳定综合收益 | 保留全部74/35通道，不再大规模搜索特征子集 |
| 第二轮 | 优化集成权重的内部收益未稳定迁移 | 主线为一个端到端模型，不做连续集成权重搜索 |
| 第三轮 | 顶部两层微调未胜出；联合改损失的stop收益未迁移，后期过拟合明显 | 不沿用普通CE+低回归的失败组合；设置冻结/解冻配对对照，保留加权CE和0.8回归，限制训练预算 |
| 第四轮 | 加宽基线有收益，复杂交互与中性分解未胜出 | 优先加宽已验证的Fusion，不同时加入跨模态Transformer、分解头与新损失 |
| 第五轮 | 音视频专家较弱；门控收益小且种子不一致 | 不再默认独立专家相加；诊断音视频增量，但不强迫模态等贡献 |
| 正确队友版本 | 顶部两层微调、较小头学习率与量化后校准获得可部署候选 | 将文本编码器真正纳入训练；FP32、量化、校准分别比较，保留可解释的单因素对照 |

第三轮与队友结果并不逻辑矛盾：第三轮使用fit3004/stop391，队友使用全部train3395并在官方valid选epoch；损失、缺失率、头学习率和部署精度也有差异。现有证据不能把差距唯一归于编码器微调，也不能认定微调已经被第三轮普遍否定。

## 3. 主线选择与模型规模

**主线：在线MiniLM编码＋加宽门控Fusion，检验更充分的端到端学习；单模型直接服务第三问。** 暂不更换到另一种预训练编码器，不将768维预计算特征遮挡路线作为本轮主线。

本地MiniLM checkpoint按safetensors张量计数含22,713,728个参数，其中顶部两层3,548,928个；实际参与任务的参数须排除未使用的pooler并由程序重新审计。`Fusion(dim=192)`实测206,291个参数。完整组合约2292万参数，主候选更新编码器六层及嵌入，区别于此前仅优化约7万—10万参数的冻结特征任务头。MiniLM仍属于轻量预训练编码器，本方案不将其描述成大型语言模型。

使用同一组种子`20267001/20267002/20267003`，先做以下4×3个训练：

| 编号 | 文本可训练范围 | Fusion维度 | 验证目的 |
|---|---|---:|---|
| R0 | 顶部两层 | 64 | 正确队友方法在统一协议下的参照，不是本轮主推结构 |
| R1 | 顶部两层 | 192 | 相对R0只改变融合容量 |
| R2 | 六层及嵌入 | 192 | 相对R1检验更充分的文本适配；主候选 |
| R3 | 全冻结 | 192 | 与R1对照，隔离在线编码和真正微调的作用 |

共同设置：长度50、全部音视频通道、Fusion dropout0.25、缺失概率0.3、加权CE+0.8SmoothL1、AdamW、weight decay0.01、有效batch32、梯度裁剪1。最多10epoch，保存最佳及末轮；不以末轮强行交付。融合头lr2e-4；R1/R0顶部两层lr2e-5；R2顶部两层同值，底部四层5e-6、嵌入1e-6。R2的比较是“扩大更新范围及其固定分层学习率”的整体对照，不能声称只改变参数数目。

冻结权重、dropout模式、实际更新参数数目单独记录；所有组统一编码器train/eval规则，不能只给某一组额外关闭dropout。8GB显存下先测真实batch32；不足时全组统一microbatch8、累积4步，记录数值路径变化。主线不加逐模态辅助头、不加门控解释KL、不加新的分类—回归一致性损失，以免无法归因。

## 4. 数据、选模与完整train重训

1. **开发阶段**复用第三至五轮已保存的原视频分组fit3004/stop391边界，核对样本ID和分组哈希。仅fit拟合标准化与类别权重，学习网络参数；stop选择epoch与架构。视频分组不等于受试者独立。
2. 每epoch记录干净stop，以及文本/音频/视觉各30%中间连续缺失，共4条件。按干净ACC优先、宏F1其次、较低一致性MAE再次、较早epoch最后选择检查点；不得偷偷用点状缺失加入同分规则。
3. 架构比较按三个种子指标均值。相对R0，要求干净宏F1下降≤0.005、中性F1下降≤0.02、三种缺失平均宏F1下降≤0.01、四条件平均MAE增加≤0.02。合格候选按干净ACC均值排序；同分优先R0，再按较少可训练参数、固定编号排序。记录逐种子差值；只有至少两种子提高且均值增加≥0.5个百分点，才称为“进入改进候选”，否则保留R0并如实记录失败。
4. 冻结架构及各自种子epoch后，入选组和R0都从同一通用预训练版本重新初始化，在**完整3395条train**上重训；各组各3种子。重新拟合train标准化和类别权重；不沿用已经见过stop的小样本训练权重继续追加epoch。
5. 本阶段不读取valid选择重训epoch。首选交付种子预先固定20267001，不挑valid上最高的种子；另外两种子用于稳定性报告。若R0最终胜出，仅重训一组3种子，不重复计算。
6. 官方valid728条用于完整train模型的报告和下一节明确规定的后处理校准。它仍是内部验证集，历史上已反复使用；不能描述为新盲测。不访问test进行本轮比较、调参或筛选。附件4无标签，仅在模型与后处理锁定后输出预测解释。

开发共12次训练、最多120epoch；完整train重训最多6次、最多60epoch，合计最多18次/180epoch。没有默认七编码器集成。训练时间在环境预检后由R0/R2各一个epoch实测估算；现阶段不拿服务器历史秒数推算本机，更不承诺固定准确率。

## 5. 量化与校准单独验收

先保存完整FP32权重，导出单样本CPU ONNX编码器并量化int8；Fusion保持FP32。对R0及入选结构的三个完整train模型分别记录FP32与int8干净/缺失结果。量化路径是模型的一部分，不能只报告FP32成绩却交付未经核查的int8模型。

仅对最终部署精度的预测搜索偏置：负向、中性各`{-0.2,-0.1,0,0.1,0.2}`，正向0，共25点，零偏置纳入。对每种架构使用三种子共享的一组偏置，按原视频进行5折分组校准：四折选偏置、一折出预测，拼接计算折外指标；样本ID必须严格一致，不只核对类别数组。

折内偏置以平均ACC为目标，宏F1/中性F1/MAE护栏同上并相对自身无偏置结果检查；同分优先较小L1范数、零偏置。只有折外三种子平均ACC严格提高且护栏通过，才在完整valid拟合最终共享偏置，否则使用零。报告“折外校准结果”和“完整valid拟合后结果”两列。前者只验证偏置步骤，不能称整个研究流程独立外部评估；历史valid复用风险仍在。

中性F1是护栏而不是再新增一个中性分类器。第三、四轮已经表明降低损失权重或更换分解头不保证收益，这次不追加这些自由度。

若部署量化损失明显，先检查输入、动态轴、逐样本路径和算子一致性；不无限扩展偏置范围追分。可以保留未校准int8候选或停止宣布替换成功。现有编码器int8约22.88MB，单个192维Fusion参数约0.83MB，预计可保留第三问材料空间；最终必须实测**全队总附件**不超过50MB，而非只检查模型或第三问子包。三份完整编码器不得默认全部打入比赛包。

## 6. 第三问解释：解释最终模型的真实输入变化

第三问以三模态完整输入下的极性和强度为主；缺失面板作为鲁棒性与解释稳定性检查，不再把大量缺失条件的混合分数置于完整输入ACC之前。

### 6.1 模态作用

固定原预测类别c，分别移除文本、音频、视觉，计算最终部署模型的目标类log概率与概率变化。每次都执行最终编码器、Fusion、偏置和同一解码。门控权重仅作诊断，不能当贡献度。

文本干预采用保持50位置坐标的UNK替换，再运行编码器，并更新池化掩码；音视频在标准化后置零并更新掩码。文本解释准确称“输入词元替换敏感性”，不是删除自然语言后重新分词，也不声称情感因果来源。该做法避免预计算文本特征中继续保留被遮挡词元的原始编码信息，但仍有UNK干预分布和模型解释的局限。

三模态只需8个保留子集，可同时计算精确三模态Shapley分解作交互核查：取`v(S)=log p_c(x_S)`，按三个模态所有排列平均边际增量，验证`Σφ=v(全部)-v(空集)`。空集使用模型在三路掩码均空时的有限输出，含模型先验，不能伪称真实中性。主要参考模态按正贡献最大者确定；若都不为正则标记“无单一支持模态/需联合判断”，不强制每条样本给出误导性最大模态。删除效应与Shapley可能不同，字段及定义分别记录。

### 6.2 局部证据和质量检查

- 对各模态有效位置计算单位置干预；比较1—3位置连续窗口的联合干预效应。文本每次重新编码，局部窗口固定原类别，不在干预后换解释目标。
- 文本通过词元offset映射原文；音视频复用A的对齐/未对齐特征匹配和视频流核查。多候选匹配、名义采样率推算、时间越界、映射失败明确标注，不能把第k个对齐位置直接写成k/采样率秒。
- 在valid固定样本上比较高贡献窗口与等长度随机窗口的删除效应；保留正/负效应、类别翻转率、Shapley加和误差。该实验检查模型敏感性，不是人工证据正确率，也不能代替人工标注。
- 如量化改变原预测类别，FP32/int8解释比较既报告固定共同目标的差异，也报告各自实际预测目标；不能把不同目标解释直接求相关。
- 不以“让三模态贡献均匀”训练模型。主线先使用无需额外训练的忠实干预解释；解释约束训练作为未来独立消融，不在本轮临时追加。
