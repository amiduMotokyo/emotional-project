## 3. 方案速览

目标：检验同模型库、同预算下，DE集成权重搜索是否优于等权、贪心与随机搜索，以及权重正则和类别偏置是否有额外收益。

- 模型沿用`robust_gate`和384维MiniLM输入一致性协议；不混入A的768维编码后遮挡模型。
- 每库6模型：学习率`0.0004/0.0008/0.0016`各配2个训练种子。其余参数固定默认。
- 完整版两个库共12次训练，每次18轮，上限216epoch。库A种子`20261001/20261002`，库B种子`20261003/20261004`；最终候选库预设为A，B用于重复性检查。
- 官方train内部约90%拟合、10%选检查点；valid供集成层三折交叉拟合。基础模型不在valid选检查点。同一样本的所有缺失场景必须在同一折。
- 对照R0—R7：固定单模型、选单最佳、等权、贪心、随机权重、DE、正则DE、正则DE加类别偏置。
- 主指标仍为四场景平均`Macro-F1 − 0.15 MAE + 0.05 Pearson`；ACC单列。集中度惩罚系数0.01，偏置在对数概率空间操作。
- 每次搜索300请求，种子`11/23/37`的预测平均，不挑最好种子。完整折外比较27000次请求，搜索复用预测缓存。
- 增益门槛：两库平均相对R0的ΔS至少0.005、各库不为负，且均满足clean F1下降≤0.01、MAE增加≤0.02。完整选型规则查主设计。
- 第一轮test已经查看过；本轮锁定后只能称“复评”，不能称新的盲测。达不到门槛则保留第一轮已锁定提交模型。

短训排名与STG/SAND特征选择属于后续独立分支，**不在本轮主预算内**。
