# 第三轮准确率优化实验

负责人：C。此文件保留训练前固定的方案，执行状态与数值见[结果记录](第三轮准确率优化实验结果.md)。

目标：检验损失权重、缺失增强强度及文本局部微调能否提高干净输入准确率，同时限制宏 F1、缺失鲁棒性及强度回归退化。沿用项目协作 Skill；复用 B 的 Fusion 与数据接口，不修改第二轮代码和产物。

## 固定协议

- 附件2对齐版，沿用第二轮视频分组：fit 3004、stop 391、valid 728；归一化仅由 fit 拟合。按原视频前缀分组，不声称主体隔离。
- fit 反向传播；stop 选择 epoch 和训练配方；valid 三折按视频分组校准及选择最终候选。test 727 条只在本轮锁定后复评。历史上已经查看过 test，不能称为全新盲测。
- 每个配置运行种子 20262001、20262002、20262003，各18 epoch。干净 stop Accuracy 优先，同分依次选宏 F1、较低 MAE、较早 epoch。
- 五组单因素/联合实验：原加权 CE + 0.8 回归 + 0.8 缺失概率；仅改普通 CE；仅改回归系数0.3；仅改缺失概率0.4；三项一起改。Fusion 学习率8e-4、AdamW、weight decay0.01、batch64。
- 复用8份0.8缺失视图。0.4版本以固定独立 Bernoulli(0.5) 将原视图替换为干净输入，期望缺失概率0.4；保持相同被保留缺失片段，不必重新编码。所有模型共用同一保留表，保存真实改变比例。
- 配方按三种子 stop 指标均值选。相比本轮 baseline，干净宏 F1 和三个缺失条件平均宏 F1 均不下降超过0.01，四条件平均 MAE 不升超过0.02；通过者取最高干净 Accuracy。若无改善保留 baseline。
- 使用选定配方做同源全精度 MiniLM 冻结/顶部两层微调配对实验，各3种子18 epoch、batch32。Fusion 学习率不变，文本2e-5。冻结所有其余层；冻结层保持 eval，顶部可训练层使用训练模式。输入50个词元，缺失词元在编码前置为 UNK，缺失掩码进入 Fusion。全精度冻结对照用于区分量化差异和微调收益。
- 不沿用 B 已经在 valid 上选出的微调权重；从本机预训练 all-MiniLM-L6-v2 初始化，不增加情感训练数据。冻结/微调使用相同初始化种子、损失与输入掩码。

## 集成、校准与锁定

候选限制为 baseline、所选 int8 配方、全精度冻结、文本微调的第一种子单模型和三种子等权集成，另加所选 int8 与微调共六模型等权。重复候选去重。不使用 DE 或学习集成权重。

对每个候选测试无校准和两参数 log 概率偏置：[b负,b中,0]，每参数[-0.2,0.2]步长0.05，共81点。只在 valid 每折训练部分拟合，在留出视频折预测；零偏置为平局优先，偏置平方范数越小越优先。拟合时相对该候选零偏置，约束干净和缺失平均宏F1不降超0.01。最终候选折外指标再与 baseline 三种子等权作相同 F1、MAE退化检查。有效候选取干净 Accuracy 最高；平局优先模型少、无校准，再按固定名称顺序。方法和权重先锁定，再在全部 valid 重拟合选中偏置。

主要验证面板：干净 + 文本/音频/视觉30%中段缺失。锁定后测试完整64条件（干净及7模态组合×3比例×3位置），同时报告固定 baseline 与选中候选。此处约束仅覆盖开发面板，不能保证全部缺失情况都不退化。
