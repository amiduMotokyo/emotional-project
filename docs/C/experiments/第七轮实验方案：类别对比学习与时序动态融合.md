# 第七轮实验方案：类别对比学习与时序动态融合

日期：2026-09-26；负责人：C。状态：**已完成18个开发模型、6个完整train模型，共218epoch；部署、第三问20条解释及独立解压复验完成。结果见[实验记录](第七轮类别对比学习与时序动态融合实验结果.md)。** 以下保留预设对照和晋级规则。A阶段未晋级，因此未追加AB；B2入选，部署三种子均值提高，但固定交付种子低于A0，保守保留旧包。

依据：[第六轮结果](第六轮端到端MiniLM训练与第三问交付结果.md)、[近期论文复核](../research/2026-09-26_第六轮后准确率提升文献复核.md)。本轮延续端到端文本训练，产物面向第三问，不能退回仅训练冻结特征的小任务头。MiniLM是轻量预训练编码器，本方案不将其称为大语言模型。

## 1. 目标与假设

主要目标是在可比协议下提高完整输入三分类准确率，同时守住Macro-F1、中性F1、强度预测和缺失鲁棒性。第六轮交付valid ACC为62.7747%，中性召回34.78%；三种子FP32均值61.3095%，不能拿单种子代替均值。

本轮检验两个假设：

- H1：当前训练没有充分形成类别可分的融合表示；类别监督对比损失可能改善中性与正负类的边界。
- H2：仅在压缩后的模态表示或最终概率上融合，可能丢失局部互补信息；预测之前的时序交互及逐样本模态选择可能更有效。

H1/H2均未被现有实验证明。中性样本可能具有多种形成机制，并不天然构成紧凑簇；音视频弱也可能源于输入特征的信息上限。本轮不预设必须成功，不承诺达到70%。

## 3. 阶段A：采样与类别监督对比学习

| 组别 | 模型及采样 | 损失 | 对照目的 |
|---|---|---|---|
| A0 | 原MiniLM＋Fusion；自然分布shuffle | 原任务损失 | 同轮基线 |
| A1 | 与A0相同；类别均衡批次 | 原任务损失 | 隔离采样变化 |
| A2 | 与A1相同；增加训练期投影头 | 原任务损失＋0.05×SupCon | 隔离对比学习分支 |

均衡批次按每类10/11/11条、轮换多出的名额构造。每epoch总抽样数仍为N；类内优先覆盖不同原视频和不同样本，耗尽后跨批次重采样，单批不重复同一ID。保存实际类别/原视频覆盖率和重复率。不把A1/A2的一轮变成更多更新次数。

### 3.1 对比目标的精确定义

从实际送入分类头的融合表示h接入训练期投影头：Linear(d,64)→GELU→Linear(64,64)，再做L2归一化得z。实现前核对现有Fusion中h的真实维度，不硬编码假定它等于64；投影头推理时删除。

温度τ=0.1，权重λ=0.05，本轮不网格搜索。对锚点i，只使用**不同原视频**的批内样本作为比较集合D(i)，其中同类样本为正集合P(i)。

`L_supcon = mean_i[-mean_{p∈P(i)} log(exp(z_i·z_p/τ) / Σ_{a∈D(i)} exp(z_i·z_a/τ))]`

用logsumexp稳定实现；同原视频样本从分子、分母同时排除。没有正样本的锚点跳过，整批无有效锚点时返回可微零值并记录；不把自身作为正样本。若有效锚点比例低于80%，标记采样实现/数据覆盖问题，停止A2并修正后以新版本重新运行全部A组，而非静默更改目标。

直接复用同一次含缺失增强的前向表示，不额外跑第二个文本编码视图、不使用跨批缓存或valid表征。类标签只定义样本级监督对比关系。记录CE、回归、SupCon各项与梯度范数，避免新增损失掩盖主任务。

A2−A1估计对比学习分支增量；A1−A0估计采样增量。A2只超过A0而未超过A1时，不能宣称对比学习有效。完整SFTTR还包含表征分解与融合结构，本组只借鉴其思想，不称为论文复现。

## 4. 阶段B：预测前的时序动态融合

阶段B统一使用A0自然采样和原任务损失，不先叠加阶段A胜出项。保持对齐50位置输入，暂不引入500位置未对齐输入、胶囊路由或教师蒸馏，减少无法归因的变量。

### 4.1 候选结构

文本50×384、音频50×74、视觉50×35分别线性投影到64维，加入位置编码与模态标识，保留各自有效掩码。构造以文本、音频、视觉为查询的三个融合分支：各分支以本模态序列为query、其他两模态有效序列拼接为key/value，执行一层4头交叉注意力、残差与LayerNorm、宽度128的前馈层，然后在有效query位置做masked mean，得到h_T、h_A、h_V。

三个分支共享交叉注意力及前馈参数，靠输入和模态标识区分；分类和回归共享最终融合表示。增加模块的精确参数数目由实现审计，不预填估计值。与原Fusion比较代表整个结构替换，不能声称只改了一个门控函数。

| 组别 | 三分支输出的汇总 | 目的 |
|---|---|---|
| B0 | 固定文本分支；文本完全不可用时均匀汇总其余有效分支 | 检验时序交互结构本身 |
| B1 | 有效分支等权平均 | 检验多分支信息，不引入学习选择 |
| B2 | softmax动态权重加权 | 检验逐样本主要模态选择 |

B2门控输入为三个模态交互前的池化表示与可用性标记；MLP为195→32→3。不可用模态logit屏蔽；h=Σw_m h_m。使用可微soft权重，不训练argmax硬路由；“主要模态”诊断可取最大权重，但第三问解释仍必须由干预产生。B0/B1没有可训练选择器，因此B2相对它们含少量额外参数，应如实报告。

三个分支在所有B组都执行相同前向计算，固定选择导致无贡献分支没有相同梯度，属于设计差异。query全空时该分支无效；key/value全空时交叉注意力增量置零，保留本模态残差；三模态全空时返回有限的先验输出，禁止NaN和把padding当证据。

### 4.2 与既有工作的区别及后续边界

本结构是受MODS启发的简化项目方案，不是完整MODS：没有图胶囊压缩，也尚未使用未对齐长序列。它区别于第五轮最终概率融合，但仍需与第四轮曾失败的复杂交互结果谨慎对照，不能仅凭名称判断先进。

B0/B1超过A0只能支持新融合结构；只有B2在相同设置下稳定超过B0和B1，才支持“动态选择”这一解释。500位置输入、共享/私有分解、EBMC阶段训练、MISR风险方差均列为后续候选，不属于本轮默认预算。

## 5. 统一选模、晋级与组合规则

### 5.1 每种子最佳epoch

每epoch评估干净stop，以及文本/音频/视觉各自中部30%连续缺失共三个固定条件。按干净ACC、Macro-F1、较低一致性强度MAE依次排序，同分取更早epoch。63条件面板留到锁定模型后，避免放大开发计算量。

### 5.2 三种子候选晋级

对照均值基于各自最佳epoch，不混用末轮。候选须同时满足：

- 干净ACC均值较指定对照提高至少0.5个百分点，且至少2/3配对种子严格提高。
- 干净Macro-F1不下降超过0.005，中性F1不下降超过0.02。
- 三个缺失条件平均Macro-F1不下降超过0.01。
- 干净及三个缺失条件平均一致性强度MAE不增加超过0.02。

这些是工程初筛阈值，不是显著性证明。必须另报中性precision/recall、全部混淆矩阵、每类F1、三种子标准差和配对差值。若只有召回提高而precision大幅下降，不将其解释为表征更清晰。

阶段A：A1、A2相对A0判断是否入选；A2相对A1另外判断对比机制证据。阶段B：B0/B1/B2相对A0判断结构候选；动态机制证据要求B2相对B0、B1均通过门槛。候选同分依次取Macro-F1更高、参数更少、固定编号更前者。

### 5.3 最多增加一个组合组

只有A阶段和B阶段各有候选通过对A0的门槛，才训练AB：在胜出的B结构上使用胜出A组的采样/损失，仍为三种子10epoch。A2胜出则包含SupCon，A1胜出则只有均衡采样。AB必须超过两者中更强的单独组并通过同样护栏，才允许替代单独方案；否则选择单独组。

六个基础组和可选AB比较完成后，锁定一个候选及A0进入完整train重训。无候选晋级则锁定A0，记录方法未获支持；禁止为了追分继续扩展权重、温度或种子。

## 6. 完整train、部署与实际替换

1. 每组各种子使用开发阶段自己的最佳epoch，从通用预训练权重重新初始化，在完整3395条train重训。最多候选＋A0两组共6次；不读valid调整轮数。
2. 同时保存完整FP32 checkpoint、归一化、配置、词表/编码器版本。先汇总FP32指标，再比较int8编码器＋FP32融合模型，不把量化和结构收益混在一起。
3. 校准沿用第六轮25点共享偏置及五折原视频分组折外检查，零偏置必须纳入；只有相对自身未校准结果折外改善且护栏通过才采用。报告未校准、折外校准、全valid拟合后三列。校准检验不是整套模型的嵌套交叉验证。
4. 若量化平均损失超过0.5个百分点，触发输入/算子/逐样本路径审计；这个值是排查阈值，不授权无限调参。量化不能保持收益时，不声称部署版本改进。
5. 候选在最终部署路径上相对同轮A0仍满足第5节门槛，才称可替换候选；预固定种子也需单独比较。未满足则保留历史可用交付包，不覆盖。队友63.74%和第六轮62.77%作历史参考，不冒充同协议消融。
6. valid已被反复使用，即使通过门槛仍称内部验证改善。本轮不重新读取历史test来决定是否采用方法。

- 文本UNK干预后重新编码；音视频置零并同步有效掩码；解释必须运行最终部署精度和校准路径。
