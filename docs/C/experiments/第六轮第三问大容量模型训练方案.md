# 第六轮：面向第三问的大容量融合模型与解释交付

用户授权：结合队友v4与前五轮经验训练，产物直接用于第三问。采用附件2/4共同提供的aligned_50、768/74/35维特征，不再以MiniLM小型任务网络为本轮主模型。模型共享实现放B/src，C负责训练、搜索、评估、打包；复用B的解释算法与A的证据定位，保留旧接口。

## 固定设计

七模型：双向GRU隐藏维128×2、160×2、192×1；跨模态Transformer为192维6头2层、256维8头2层。模态池化、可用性门控、融合主头和逐模态辅助预测头；配置见`C/configs/q3_round6_large.json`。不使用队友不可复现的缺失依赖或直接改写其权重。

仅从附件2 train 3395条学习，按原视频GroupShuffleSplit(seed2026，dev_fraction0.2)拆分内层训练/开发。归一化仅拟合内层训练，避免先使用全部train统计量。官方valid 728条在模型、epoch、权重、偏置锁定及完整train重训后评估，不作为新一轮优化输入；由于历史多轮使用过valid，不能称为全新盲测。原始pickle整体读取时会反序列化test，但本轮不索引、不统计、不训练、不选型、不评估test。附件4只用于最终20条预测与解释。

每个内层模型最多24epoch，patience6，AdamW lr0.0005，余弦退火最低为初始0.1倍，wd0.01，batch32，clip1。主损失加权CE＋0.8SmoothL1；类别权重逆平方根。逐模态辅助相同目标按可用分支平均，权重0.1；分类期望极性与回归/3的平方一致性权重0.05。每四个batch，对干净输入前8条计算B既有的真实类别模态删除效应，以停止梯度的正效应占比监督门控（权重0.05）。不把门控权重直接当作解释。

采用C连续缺失采样，概率0.6—0.8，按模型配置。由于直接使用上下文化预计算文本，本轮遮挡的是特征位置与掩码，不能声称输入级UNK重编码或与前五轮缺失结果严格等价。第三问完整信息预测为主要用途，原文删除因果解释不作承诺。

内层epoch按`0.7*clean_ACC+0.3*clean_macroF1-0.05*clean_MAE+0.05*missing_mean_macroF1`选择，缺失面板为文本/音频/视觉30%中段，强度按分类一致性解码；同分保留更早epoch。冻结epoch后在完整3395条train重新拟合归一化并重训。

## 集成与评价

内层开发保存七模型预测，比较单模型、七模型等权和DE搜索的非负归一化权重＋负向/中性偏置（正向偏置固定0），不搜索不会改变硬预测的温度。DE固定30代、popsize8、seed20266000；目标为准确率主导、宏F1次级、真实强度MAE辅助，禁止用类别编号充当强度目标。

搜索及候选约束相对等权：clean宏F1和缺失平均宏F1下降≤0.005，clean中性F1下降≤0.02，四条件平均MAE增加≤0.02。按合格候选clean准确率选择，同分优先等权，其次更高宏F1、更低MAE。完整train重训后不重调集成参数。官方valid同时报告锁定集成、等权对照、七个单模型及逐类指标；仅作固定报告。历史第五轮和队友v4作为非严格配对的背景比较，不将差值归因于单一创新。

## 第三问产物

输出极性、一致性强度、概率；三模态有符号删除效应、绝对占比、主要参考模态；各模态50位置局部效应和宽度1—3联合删除窗口；原文字符片段、音频时段、视觉关键帧和20张解释卡。使用整个最终集成的固定原预测类别`log(集成概率)+bias`为解释分数，每次消融重新运行完整集成，禁止用单成员解释冒充集成解释。上下文化文本特征可能保留被遮挡位置的信息，解释限定为特征输入敏感性。

复用B/src/q3_explain.py的模态/局部计算、B/scripts/run_q3.py的导出流程和A/src/evidence_locator.py的映射。增加prepare_aligned可选接口保持旧384维流程兼容。所有定位失败和多帧匹配显式保留，不编造时间；音视频名义采样率时间仅是近似映射。附件4没有标签，不计算准确率。

本轮独立输出`C/outputs/q3_round6_large_v1/`；比赛可用Q3组件包输出`C/outputs/submission/q3_round6_large/`及同名zip，不覆盖原总提交包。包含权重、归一化、锁定参数、代码、配置、环境、验证结果、附件4 CSV/JSON、解释卡、可视化与证据预览，提供给原始data根目录的一键推理入口。检查组件包<50MB；全队总附件限额仍需最终合包复核。只打包本任务必要自生成材料，不复制原始数据或整个本机环境。

## 检查与复现

入口`C/scripts/run_q3_round6.py`，分阶段可恢复；源代码、配置、方案及数据哈希固定。训练前核对七模型参数规模、全缺失有限输出、被掩码值不变性和梯度；训练后重算指标、核对分组隔离及归一化范围、完整重训epoch和模型数量。最终核对20条样本与媒体、解释加和占比、重新推理一致性、导出图表与压缩包大小。
