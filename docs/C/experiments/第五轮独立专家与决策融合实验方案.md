# 第五轮独立专家与决策融合实验方案

用户已授权按“独立专家→互补诊断→决策融合；互补不足则更换表示”的顺序实施。本文件在本轮新增模型训练前固定。状态及实际结果另写结果文档，不修改冻结方案。

## 目标与数据

保留第四轮wide_control作为基线，复用第四轮text_only三种子模型；新增不接收文本信息的音视频专家。保持原MiniLM int8、fit 3004/stop 391/valid 728、输入级UNK、8个缓存训练视图及原视频分组协议。原始train 3395；仅fit拟合归一化。训练参数沿用第四轮：18epoch、AdamW 0.0008、权重衰减0.01、batch64、加权CE＋0.8SmoothL1、dropout0.25、梯度裁剪1。种子20263001/2/3。

音视频专家分别投影74/35维至64，掩码池化后拼接两路摘要及可用率，接128→64→分类与强度头。音视频专家不得读取文本值或文本掩码。

## 顺序与分支规则

首先在stop的干净及三种30%中段单模态缺失条件上报告错误互补性。以干净stop的“文本错且音视频对”占全部样本比例为路线依据：三种子平均至少5%，且至少两个种子达到3%，进入融合分支；否则结束融合分支并转向文本表示实验，后者需单独固定编码器兼容性及方案后运行。阈值仅为本轮工程筛选规则，不是统计显著性标准。

stop参与专家epoch选择，因此诊断不是独立泛化评估。任一专家正确的oracle仅为诊断上限，不是可部署成绩。还需报告文本对且音视频错、共同错误、预测分歧，避免只汇报可纠正样本。

## 折外预测与融合

进入融合后，在fit内按原视频做三折StratifiedGroupKFold（seed20265000）。每折仅用其余两折训练文本、音视频专家，类权重和音视频归一化也只用这两折；stop按该折归一化用于选epoch，不使用held-fit标签选epoch。每个种子共6个折内专家，三种子共18个；held组与训练组无交集。缓存文本编码器冻结且无标签训练，可复用原视图，但按原fit行号严格索引。

折外面板含干净、8个既有缺失视图、整路文本缺失、整路音视频缺失，共11个。整路缺失专家由决策层严格屏蔽，不读取其预测；全部缺失时分类均匀、回归0。可用率为当前有效位置数除以干净有效位置数，分母为0时记0。

融合器输入两专家概率6维、归一化回归2维、熵2维及模态可用率3维，共13维；13→8 tanh→2输出门控，末层零初始化。仅折外数据训练，固定200步全批AdamW，lr0.01、wd0.01，目标为按fit类别加权的负对数似然＋0.8SmoothL1。面板权重：干净0.5、8缺失视图合计0.25、整路文本/音视频缺失各0.125。无valid调门控超参数，无类别偏置搜索。推理使用完整fit训练的两个专家；存在折内与完整fit模型分布差异，作为局限记录。

## 选型与复评

候选：第四轮加宽基线、文本专家、音视频专家、按可用性简单等权融合、学习门控融合。三种子分别组合、分别计算指标后取均值，不跨种子集成。valid四条件面板；相对加宽基线，干净及三缺失平均宏F1退化不超过0.01，四条件平均MAE增加不超过0.02。合格候选按干净准确率均值选择，同分优先保留基线，再按固定候选顺序。若新候选无增益，保留基线，不能继续依据test改动本轮方案。

锁定后只比较基线与胜出候选，复评64条件（1干净＋7模态组合×3比例×3位置）。历史test不是盲测。保存三种子逐样本概率、强度及指标。缺失约束仅覆盖开发面板，不能保证64条件逐项不退化。专项附件3/4不参与训练、选择或评估；不自动替换提交模型。
