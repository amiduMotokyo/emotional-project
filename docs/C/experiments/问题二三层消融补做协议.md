## 操作边界

“无掩码”实验不让padding参与运算：保持原始支持范围及原始缺失处理，仅对人工新增缺失保留原掩码，从池化、可用比例和门控屏蔽三个通路同时隐藏新增可用性变化；输入依然删除为零或UNK。它检验的是新增缺失显式掩码，不能声称同时删除了所有原始有效掩码。

均值融合只替换门控权重，保留模态池化向量拼接、可用比例和任务头，不声称删除了全部隐式模态权重学习。交叉注意力在原投影之后、池化之前加入共享四头跨模态序列交互及残差归一化，和原Fusion严格对照；不再复用第七轮更换整个主干的分数。专家组增加文本、音视频两个联合训练的线性任务分支，依可用性平均后与原主头输出各占一半，沿用同一最终任务损失；它不是第五轮独立预训练专家的复现。

CE only的强度指标不作为有效模型能力报告；SmoothL1 only的分类指标亦不报告。回归单任务以原始回归MAE/Pearson与联合模型原始回归比较，不使用未训练分类头进行一致性映射。保留原始预测以便核查，但不将未监督任务结果写入性能排名。

新增结果只用于论文消融，不自动替换既定B₀预测模型及附件3、4结果。由于固定10轮与历史最佳epoch选模不同，新基线分数不能与历史63.74%直接比较或归因；本轮只进行内部受控差值分析，仍不是独立盲测。
