# 第四轮：序列交互与中性/极性分解

负责人C；用户已授权实施。本文在训练前固定，运行结果另存，不随观察到的分数改写。

## 目的与假设

当前B Fusion先独立池化，再融合三个向量，对独立音频帧及掩码置换不敏感。检验池化前跨模态交互是否改善分类；另检验中性概率与非中性极性分解是否比普通三分类更合适。已有卷积/GRU试验没有证明更复杂时序结构必然更好，因此本轮不将结构复杂度视为收益证据。

## 固定实验

六组：baseline（原B Fusion）、text_only（相同冻结文本的单模态）、wide_control（仅增大原Fusion隐藏维度）、factorized（原Fusion换分解头）、interaction（轻量跨注意力）、combined（交互加分解头）。每组三种子20263001/2/3，各18 epoch，合计18模型324 epoch。

沿用第二轮fit3004/stop391的视频分组、fit-only音视频归一化、valid728以及原八份输入级缺失视图。编码器保持原MiniLM int8 ONNX，batch1编码；不读取768维文本替代本轮表示，不增加情感训练数据。所有组固定加权CE＋0.8 SmoothL1、缺失抽样概率0.8、batch64、Fusion学习率8e-4、AdamW weight decay0.01、梯度裁剪1、头部dropout0.25。虽然第三轮联合配方stop稍好，但valid未胜出，故使用该轮保留基线的原始训练配方作结构比较。

stop仅用于epoch选择：干净Accuracy优先，其后宏F1、较低MAE、较早epoch。训练配方不在本轮搜索。valid选结构：对三个独立模型分别计算指标后取均值，**不先平均概率**；相对同种子基线均值，干净宏F1及三缺失平均宏F1下降各不超过0.01，四条件平均MAE增加不超过0.02。通过者取最高干净Accuracy；平局优先baseline，再取参数少、固定名称顺序。报告种子SD与逐种子差值，避免只报告最好种子。

开发面板为干净及文本/音频/视觉各30%中段缺失。锁定后仅复评baseline及选中结构的全部三种子，固定64条件（干净＋7组合×3比例×3位置）。不按test挑种子、改结构或追加候选。本轮暂不做集成、校准或教师蒸馏；若无结构收益即保留负结果。valid是反复使用的内部验证，test也是历史已查看过的复评集，不声称全新盲测或泛化显著性。

## 新结构与接口

interaction保留50步序列，分别投影到64维，加共享可学习位置向量；以文本作query、拼接音视频作key/value，采用一层四头cross-attention（dropout0.1）。交互后再池化。保留原文本摘要残差和独立音视频摘要，文本缺失时后者仍可进入预测。缺失query被清零，缺失key被排除；额外有效零哨兵避免key全部缺失时出现NaN，音视频均无观测时交互更新强制为零。

该模型不假定词元与音视频严格逐位置同步，不把注意力权重当作真实时间对齐。返回的第三项仅为可用比例的归一化诊断值，不是训练得到的解释贡献，不用于本轮指标。

wide_control的隐藏维度在64—160整数中按与interaction参数量最接近确定，只看参数量、不看标签或分数；全部参数都参与计算，不用虚设参数凑数。这是容量对照，不能排除优化难度等所有混杂因素。

factorized头输出中性logit q、非中性条件下正向logit r，以及独立强度logit。类别概率为P中=σ(q)、P正=σ(-q)σ(r)、P负=σ(-q)σ(-r)。以logsigmoid实现稳定log概率，再使用与基线一致的类别加权负对数似然；强度头仍为3tanh。没有硬级联、没有新增两套任意辅助损失；分解本身不增加类别分布的表达能力，实验检验的是归纳偏置及学习效果。

共享输入遵循B/C既有接口：text[B,50,384]、audio[B,50,74]、vision[B,50,35]和三个bool掩码；输出分类logits或归一化log概率[B,3]、强度[B]、诊断[B,3]。标签0负/1中/2正，缺失词元先UNK再编码。实现位于C/src/q2_structural.py，直接复用B Fusion与MaskedAttentionPool，旧共享源码与各轮产物不修改。
