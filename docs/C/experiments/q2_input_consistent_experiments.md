# 问题二：输入一致性修订实验

状态：已训练、完成验证网格并生成附件3结果；归档于 C/M5、M7。

## 目的与关键发现

原流程把完整 `text_bert` 先编码为 MiniLM 向量，再通过池化掩码删除位置。附件3的缺失词元却是在编码器输入中表现为 `[UNK]`。上下文编码会把被删词的信息带入其他位置，因此原实验没有严格复现转写输入损坏。

复核也发现，随包动态量化 ONNX 编码器对同一词元使用单条和批量输入时，输出会有可测差异。旧缓存和附件3单条推理由此使用了不同向量。修订实验统一采用随包 int8 ONNX 编码器，并对训练、验证、受损文本视图和附件3按单条输入。重建缓存后抽样复算，与同批次单条ONNX输出逐项一致。

旧缓存和旧结果保留作历史记录，不与本实验的指标直接合并比较。旧实验所示方法是“编码后特征遮挡”；文献简化变体的结果也没有在本次统一接口下重跑。

## 数据和掩码

使用 `aligned_50.pkl`：训练3395条、验证728条；附件3的30个对齐样本只作最后推理。文本向量为MiniLM输出384维，音频74维，视觉35维。音视频的均值和标准差只在训练集、原始有效位置拟合，标准化后无效点仍设为零。

对模态 (m) 的位置 (t)，观测状态来自其基础有效掩码和新增人工遮挡掩码。填充、原始无效值和人工缺失分别处理。缺失区间在50步原坐标上直接取连续起止位置；不根据有效点总数重编号。训练时每条样本独立决定是否缺失、缺失模态组合、比例与区间。

训练集每条样本以0.8概率进入受损视图，缺失比例从10%、20%、30%、50%中抽取，七种非空模态组合均可出现，位置随机。保存8组互相独立的词元级受损视图，训练周期中轮换。被遮文本在编码前替换成 `[UNK]`，保留attention mask；音频和视觉在相同区间由掩码屏蔽。附件3中实测 `[UNK]` 的attention保持为有效，这与修订后的词元替换规则一致。

## 模型与训练

同一训练协议下比较三种结构：干净输入门控基线、连续缺失增强门控模型、带位置卷积和双向GRU的时序模型。最终选择由验证集比较，不预设更复杂结构一定更好。

基础分类和回归损失为：

\[
\mathcal L=\operatorname{CE}_{w}(c,p)+0.8\,\operatorname{SmoothL1}(y,\hat y),
\qquad
w_c=\sqrt{N/(3N_c)},\qquad \hat y=3\tanh(z).
\]

三种候选均使用AdamW，学习率 (8\times10^{-4})、权重衰减0.01、batch size 64、最多35轮、早停7轮、梯度裁剪1.0。随机种子为20260924、20260925、20260926。标准化和所有参数仅使用训练集拟合。

每轮在干净验证集及文本、音频、视觉各自30%中段缺失场景上评估。选择分数为四个条件平均后的 `Macro-F1 - 0.15×MAE + 0.05×Pearson`。三种子平均选择分数为：

| 候选 | 平均选择分数 ± 标准差 | 63种条件下平均 Macro-F1 | 63种条件下平均 MAE（未做符号一致性解码） |
|---|---:|---:|---:|
| 干净输入门控基线 | 0.5100 ± 0.0107 | 0.5642 | 0.6552 |
| 连续缺失增强门控 | 0.5182 ± 0.0080 | 0.5706 | 0.6354 |
| 时序门控候选 | 0.5162 ± 0.0064 | 0.5652 | 0.6472 |

网格包含7种非空模态组合、3种缺失率、3种区间位置，共63种条件，每种728条验证样本。三类完整网格的MAE按原始回归头输出统计。最终采用连续缺失增强门控结构，种子20260924；时序候选未带来更高的验证选择分数，差异不大，不据此断言某结构普遍更优。

## 最终验证与缺失规律

最终模型原始双头输出及交付解码结果如下。交付时由分类结果约束强度符号，并将Neutral强度设为0；因此分类指标不变，强度指标按实际交付规则重算。

| 指标 | 原始双头 | 实际交付解码 |
|---|---:|---:|
| Accuracy | 0.6168 | 0.6168 |
| Macro-F1 | 0.5942 | 0.5942 |
| MAE | 0.5971 | 0.5901 |
| Pearson | 0.6488 | 0.6490 |

交付解码下，负向/中性/正向F1分别为0.6504、0.4482、0.6841；混淆矩阵（行为真实类别，列为预测类别）为 `[[133,31,42],[30,80,74],[40,62,236]]`。中性仍是主要分类误差来源。

最终选中模型的63种条件均按交付解码重新评估，平均Accuracy为0.5972、Macro-F1为0.5761、MAE为0.6076、Pearson为0.6071；最差条件Macro-F1为0.5306。按缺失模态对所有比例和位置取平均：

| 缺失模态 | Macro-F1 | MAE |
|---|---:|---:|
| 文本 | 0.5638 | 0.6210 |
| 音频 | 0.5949 | 0.5896 |
| 视觉 | 0.5925 | 0.5896 |

按缺失率对全部模态组合和位置取平均，10%、30%、50%的Macro-F1分别为0.5884、0.5769、0.5630；MAE分别为0.5959、0.6085、0.6184。文本缺失影响最大，缺失增加时整体Macro-F1下降、MAE上升。音频缺失的影响较小，视觉介于两者之间。三模态同步或错位缺失的全部数值见 `served_grid.csv`。

交付强度与极性一致：Neutral固定输出0；Positive不输出负值；Negative不输出正值。此解码在验证集上的MAE和Pearson优于原始回归头，因此用于附件3。
