# 第七轮模型与第三问接口

2026-09-26，C实施，B维护共享融合实现。对应[实验方案](../experiments/第七轮实验方案：类别对比学习与时序动态融合.md)。训练、部署及独立第三问推理复验已完成，性能结论见[实验结果](../experiments/第七轮类别对比学习与时序动态融合实验结果.md)。

`B/src/q3_round7_model.py::Round7Model`复用在线MiniLM，默认返回仍是`(三分类logits, [-3,3]原始强度, 三模态权重)`。分类映射0负向、1中性、2正向。训练期`last_features`为64维分类前表示；可选projector只参与监督对比训练，不写入部署融合权重。

`B/src/q3_temporal_primary_fusion.py::TemporalPrimaryFusion(mode,dim)`接受文本`[B,50,384]`、音频`[B,50,74]`、视觉`[B,50,35]`和三路`[B,50]`布尔有效掩码。三路掩码不能由特征全零值替代；填充和人工缺失由调用方区分。支持text/uniform/dynamic三种汇总模式。跨模态注意力不移动时间位置；全空key/value增量置零，全空query分支不可用，全空输入输出有限模型先验。

部署checkpoint结构沿用`architecture/model_kwargs/state_dict`。新增`architecture=temporal_primary`，`model_kwargs={mode,dim}`。`B/src/q3_explain.py`增加该加载分支，既有fusion、temporal、impute分支保持兼容。第三问继续复用`MiniLMExplanation`和附件4读取、A的原始证据定位。动态门控在每次干预后重新计算，不能视为贡献度。

`deploy_q3_minilm_round6.main`新增可选context/package/model_factory参数；`check_q3_minilm_round6.main`新增可选context/package参数，默认调用仍执行原第六轮路径。第七轮以独立wrapper显式传入其目录和模型工厂，不复制部署评估、校准或解释实现。

运行入口：`python C/scripts/run_q3_round7_representation.py --stage all`；部署入口：`python C/scripts/deploy_q3_round7_representation.py`；部署审计：`python C/scripts/check_q3_round7_representation.py`。后两者依赖完整训练与附件4推理完成，本轮已实际通过。环境使用myenv及已验证隔离依赖。`finish_q3_round7_representation.py`执行本机媒体工具适配、推理、审计、报告与独立解压复验；可移植包仍使用带参数的通用推理入口，不依赖本机工具查找逻辑。

启动前已验证：无对比正样本时零损失可反传；不同视频配对梯度有限；均衡采样数量及批内ID唯一；时序融合的全空/部分缺失、padding不变性和梯度有限；A0与原MiniLMFusion同种子初始化权重完全一致。正式训练各模型另行检查冻结权重未改变，并保存哈希和结果。
