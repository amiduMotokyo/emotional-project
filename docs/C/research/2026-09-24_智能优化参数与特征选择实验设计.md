# C：智能优化参数与特征选择实验设计

日期：2026-09-24。状态：已按B的修订协议接入DE/BPSO实验入口，通过合成数据集成验证；真实搜索和性能结论尚未产生。以下范围和预算为项目预设，不是赛题硬性要求或实测最优值。执行说明见[对接与运行说明](../experiments/q2_optimization_integration.md)，实际配置见[C/configs/q2_optimization.json](../../../C/configs/q2_optimization.json)。

本方案替代已暂停的自适应缺失采样路线。依据：[六篇文献阅读笔记](2026-09-24_智能优化文献阅读笔记.md)。第一版主线为**固定预算差分进化调参 → 二进制粒子群预选声学/视觉通道 → 调用B模型重新训练和验证 → 锁定后测试**。

## 1. 研究问题与范围

固定B的融合结构、数据版本和训练方式，回答三个问题：

1. 在相同候选训练预算下，DE能否找到优于随机搜索的超参数？
2. 固定选定超参数后，BPSO选择的通道能否用更少输入维度保持或改善完整与局部缺失表现？
3. 如果增加目标消融，针对缺失场景评价候选，是否优于只按完整场景评价？

C负责搜索器、目标函数、特征掩码、评估和日志；B维护数据加载、唯一基础模型及内层梯度训练。内层训练是评价搜索候选的必要步骤。第一版不改变融合网络，不新增重建器/教师网络，不把模型权重逐个当作粒子坐标，也不恢复自适应缺失采样。

已复用队友的Fusion、数据归一化、输入层缺失与训练函数，见[修订实验记录](../experiments/q2_input_consistent_experiments.md)。C新增外层搜索和实验编排；共享训练函数已开放超参数、固定预算、通道掩码元数据与恢复状态，旧调用默认行为保持兼容。

本次以384维MiniLM文本、加权CE与SmoothL1、词元替换后再编码，以及原坐标跨度内缺失作为统一协议。原自定义J被替换为B的四场景选择分数，避免同时改变优化器和评价目标。队友旧实验不直接充当本方案的等预算对照；E0—E5按本方案重新训练。固定18轮仍需pilot确认合理性，不能与35轮早停旧结果直接归因比较。

## 2. 数据与防泄漏

- 使用附件2同一版本的既定train/valid/test；当前优先对齐版。已有审计为3395/728/727条，运行前重新核对清单和哈希，不重分官方划分。
- train拟合归一化、分箱边界和特征相关性；valid用于候选评分、checkpoint及最终配置选择；test仅在配置、选择规则和图表协议锁定后执行一次统一评估。
- 第一版不继续切小valid，以免少数类指标更不稳定；反复使用valid会有选择偏差，通过限制候选数、单列验证/测试结果和独立test控制，不能称为无偏验证。
- 附件1的100条自生成特征不加入训练；附件3/4只用于对应最终预测，不进入搜索、预算决策或特征统计。
- 文本编码路线由B统一。若冻结预训练编码器并缓存，缓存版本须一致，缺失文本不得由raw_text或完整缓存偷偷补回。固定同一编码器后，搜索只更新融合层/任务头等B约定的可训练部分。
- padding_mask、原始无效位置、人工连续缺失mask、特征通道mask分别保存。不能将全零行一概解释成人工缺失。

## 3. 固定缺失协议

训练时每条样本以0.8概率施加局部缺失，七种非空模态组合均匀采样，比例从{0.1,0.2,0.3,0.5}均匀采样，原坐标区间随机取起点。按B的prepare_views生成8组固定视图，以(index×7+epoch) mod 8轮换；所有候选复用，mask_seed=20260924。新增文本缺失先替换为[UNK]、保留attention，再用同一个int8 ONNX逐条编码，随后池化时屏蔽缺失位置。禁止只遮挡完整上下文编码的缓存。

验证搜索面板为4个条件：完整1个，以及T/A/V各自中段30%缺失。候选复用同一缓存；按场景分别算指标后等权平均。准备阶段保存train:i、valid:i行号身份与源缓存哈希，尚无真实video_id，不用行号实施视频簇bootstrap。

最终评估面板为完整1个，加七种非空模态组合 × 比例{0.1,0.3,0.5} × 位置{开头,中间,末尾}，共64个条件。继承B的原坐标跨度定义：取三模态基础有效位置并集的首末索引[left,right)，span=right−left，width=min(span−1,max(1,round(rate×span)))，所选模态使用同一个连续区间。中间空洞不压缩；基础有效并集不足2点则不遮挡。此规则不保证每个被选模态都保留有效点，因此完整模态失效必须由模型掩码处理；比例不等于实际有效点删除比例。

比例表示原坐标上的观测跨度占比，不是秒数。部分最终条件与选模条件重合，不能称整张验证网格为未见场景；独立test在锁定全部配置之后才评价。真实专项数据与合成缺失的对应关系另行说明。

## 4. 搜索适应度与保底条件

三分类固定0负向、1中性、2正向。复用B的macro-F1、Accuracy、MAE、Pearson及逐类F1。常量预测的Pearson沿用共享实现记0的选模约定，它是数值回退而非相关性测量；真实valid包含三类，后续子集评估若缺类需要另行统一标签全集。第一版不增加weighted-F1。

对四个条件等权平均，最大化B的选择分数S：

\[
S=\frac{1}{4}\sum_s\left(\mathrm{MacroF1}_s-0.15\mathrm{MAE}_s+0.05\mathrm{Pearson}_s\right).
\]

Fusion回归头为3×tanh，天然限制到[-3,3]。训练选模与外层搜索均使用原始双头输出，最终网格同时报告原始与符号一致性解码结果，二者不能混列比较。符号解码沿用B：中性置0，正/负类约束强度符号；此规则预先固定，不在test选择。S是项目选模指标，不是官方评分公式。

训练损失为`sqrt-frequency-weighted CE + lambda_reg × SmoothL1`，类别权重仅用train计算，默认lambda_reg=0.8。**训练损失不是外层适应度**，调节lambda不会改变外层S的定义。

完整预算选择时，候选需满足完整场景Macro-F1不低于参考模型0.02绝对值、MAE不高于参考模型0.05。调参阶段参考B默认全特征模型，特征阶段参考固定DE参数的全特征模型。约束只用于最终候选选择，不把低预算候选和完整预算参考直接比较。没有合格候选则保留参考模型；不能放宽阈值直到“成功”。

## 5. 阶段一：固定预算DE调参

以[DEHB](papers/intelligent_optimization/DEHB_IJCAI_2021.pdf)中的DE机制为参考，第一版仅实现DE/rand/1/bin，不宣称完整DEHB。固定结构、batch_size和学习率调度规则，搜索4个连续变量：

| 变量 | 范围/解码 | 原因 |
|---|---|---|
| 学习率 | log10空间[−4,−2.5] | 控制内层收敛 |
| weight_decay | log10空间[−6,−2] | 控制正则 |
| dropout | [0.1,0.5]线性 | 降低过拟合 |
| lambda_reg | log10空间[log10(0.25),log10(2)] | 调节分类/回归训练权衡 |

这些边界适用于冻结大型文本编码器后的小型融合模型；若B训练范围不同，在pilot前统一修订边界，不能只对某个搜索器放宽。B默认配置单独保存，不因它落在搜索边界外而篡改基线。

把4个坐标统一到[0,1]。种群6，初始评估6个，随后3代，每代6个新候选，共24个候选请求。F=0.5、CR=0.5；父代索引互异且不同于当前目标；binomial交叉强制至少一个变异坐标；越界坐标裁剪；同分保留目标。整代从上一代快照生成，避免执行顺序改变算法。

所有候选从头训练6个epoch，在第6轮按终点S统一评分；DE子代与父代只比较同一预算。随机搜索使用同一分布、相同初始6个候选，另采18个，共24个请求。重复请求计入额度并复用结果；同一运行目录用清单锁定配置、数据哈希、编码器和源码，具体trial按参数、预算、掩码和训练种子去重。

两个搜索器各选6轮终点S最优的2个不同配置，**分别续训到18轮**，按最佳checkpoint的S与保底条件选择。共享训练函数保存当前权重、AdamW状态、Python/NumPy/Torch随机状态、CUDA随机状态、历史和最佳权重；本版采用恒定学习率，无调度器，关闭早停。CPU精确续训已验证，CUDA确定性和真实曲线仍待运行确认。

搜索训练seed=17，独立搜索seed=11。完整预算checkpoint在第1—18轮按S选择；提升阈值沿用B的1e-4。默认参考也使用相同规则。第一版每算法一次完整搜索，不把最终三个重训种子当三次搜索。

## 6. 阶段二：BPSO预选通道，真实模型复核

### 6.1 明确选择对象

固定阶段一DE产出的参数（失败则默认参数），仅搜索音频74维和视觉35维，共109个二进制位；文本384维全部保留，不声称完成了三模态所有通道联合优化。

两档保留比例q={0.5,0.75}，每种模态独立向上取整：A/V分别为37/18、56/27维。位为1表示整条序列保留该通道；它不表示选择词、不表示删除某一时间段，也不等于选择整个模态。

首版已实现Fusion内部、输入投影前的固定通道置零，归一化和时间mask沿用B，输入宽度不变。所选索引写入checkpoint的model_kwargs，恢复及附件3推理均加载同一掩码。它不减少实际密集计算量，不能声称推理加速；物理切片暂不实现。

### 6.2 训练集过滤目标（项目改造，非原论文复现）

按每个样本、每个通道，对有效时间位置计算均值和标准差，仅用于评分；模型仍输入原始时序。用train的五分位边界离散化两个摘要（重复边界合并、常量记单一类别）。回归标签按train五分位离散化；分类标签保持原三类。全无有效观测样本不计入该通道相关性估计，记录有效样本数；不足20或目标无变化时得分记0。统计量与筛选过程不接触valid/test。

采用标准定义SU(X,Y)=2I(X;Y)/(H(X)+H(Y))，分母0时取0，I使用正号求和的互信息。通道相关性a_j为其均值/标准差两种摘要对分类/离散回归两种标签的四个SU均值。通道冗余b_jk为两通道摘要四种组合SU的均值，按两通道共同有效的训练样本计算。样本不足20时保守设b_jk=1。

对所选A、V通道，令Rel分别在模态内平均a_j，再将两模态等权平均；Red分别计算模态内所选无序通道对的平均b_jk，再将两模态等权平均。最大化Q=Rel−0.2Red。先分模态归一化，避免音频维度更多而自然占优势。第一版不建跨模态冗余项，不把独立统计筛选称为捕获了所有高阶交互；真实缺失鲁棒性由后续B模型验证。

### 6.3 BPSO与公平筛选对照

标准sigmoid BPSO：种群20，初始20次评价，加30次位置更新，共620次过滤目标请求；w=0.7298，c1=c2=1.49618，速度裁剪[−6,6]，初始速度0。每个粒子初始为满足模态配额的随机子集，pbest为自身，gbest为Q最好者，同分保留原解。

速度按标准惯性项、个体项与群体项更新；按sigmoid概率采样位，再逐模态修复到固定配额：过多则删去概率最低的已选位，过少则加入概率最高的未选位；并列用该粒子的固定随机流。pbest/gbest保存修复后的实际子集。两档q各搜索一次，seed=11；只用train的Q选每档最优子集，不用valid驱动620轮筛选。

对每档q另做两类对照：①采样620个符合配额的随机子集，按相同Q选最好；②每模态按a_j选top-k。三种方法各两档，共6个候选模型，重复掩码可复用；同一固定参数从头训练18轮，在valid上按S和保底规则选该方法的一档，无合格子集则回退全特征。

这将算法搜索能力与维度压缩效果区分开。BPSO得分更好只说明过滤目标更好，只有重新训练后的结果才是预测证据。两档q只提供有限的性能—维数比较，不是真实Pareto前沿。

A1未完成，则不能声称“缺失感知目标优于只优化完整数据”；只能描述实际采用了缺失感知评价。E5失败也应记录；最终提交模型按valid确定，不按test排行榜重新挑选。

## 8. 计时、预算和三天安排

### 必须先做的pilot

pilot选默认及3个预先随机配置各训练18轮，记录第6/18轮终点S及每轮训练＋四条件验证时间。脚本计算Spearman与前两名重合数；若无重合、相关性非正或未定义，则阻止低预算hpo，需要在新运行目录设置low_epochs=full_epochs并重估预算。四配置只是诊断。当前未自动判定收敛，应检查history；若18轮不足，统一修改预算重跑。pilot估时不含准备缓存和64条件最终网格。

| 部分 | 默认累计训练epoch预算 |
|---|---:|
| pilot：4×18 | 72 |
| 两种调参：2×(24×6 + 2×12续训) | 336 |
| 特征复核：6×18 | 108 |
| E0—E5最终重训：6×3×18 | 324 |
| 合计 | 840 |

以上保守不抵扣可复用训练；不含过滤统计、缺失推理面板、初始化/读盘及故障重试。若完整预算复核必须从头训练，调参部分变为360，总量864。A1额外最多168+54=222轮。禁止把620次廉价过滤评分算成620次深度训练。

设实测单轮训练耗时为t秒，粗略训练时间为840t/3600小时，再加实际验证/推理/初始化耗时。须用较慢配置估计；B若共享同一GPU，按分配给C的可用GPU小时计，不能假设整整72小时独占。预算预测超过剩余可用时间的70%时，在正式搜索前统一缩减，两种搜索器同步改变，不在看到结果后只给某组追加预算。

**缩减方案**：DE种群6、1代，共12个候选；随机同样12个；每方法仍2个18轮复核，共192轮。保留pilot72、6个特征复核108；先完成E0—E5各1次最终训练108，共480轮。结果明确是单搜索、单重训初步实验，后续有时间优先补重训。若低预算排序失败，改为DE6初始+1代和随机12个候选全18轮，调参共432轮；必须重新评估能否承担，不能继续宣称低预算节省。

如果连缩减方案也无法完成，先交付E0/E1/E2及完整缺失评估，特征选择只保留真实完成的过滤结果并明确尚未验证下游效果；此时不能宣称参数优化和特征选择两部分都取得效果。

相对三天节点：第1天完成接口、pilot、协议冻结和方法正文；第2天做参数搜索、特征复核与关键对照，晚上写结果；第3天只做已锁定方案的最终评估、专项推理、论文更新与检查。不增加第三条新模型路线，也不为搜索挤占统稿。多阶段Hyperband/DEHB仅作为后续扩展，不列入本次必交。

搜索实现为C/src/intelligent_search.py，编排入口为C/scripts/run_q2_optimization.py，配置为C/configs/q2_optimization.json。实际训练记录和准备缓存放指定C/outputs子目录；运行说明与验证范围见对接文档。

记录包含trial_id、DE父代/代数、实际配置、预算、checkpoint、每场景指标、S、墙钟时间、峰值CUDA分配和失败原因。搜索/mask种子保存于冻结配置，训练seed保存在trial；requests.jsonl记录调用阶段与缓存命中，选择报告保留候选与回退状态。OOM/非有限损失记失败且占请求额度；禁止静默给候选改batch_size。接口错误先停搜修复，再以新版本统一重跑受影响实验。

## 10. 预期贡献与失败条件

本轮候选贡献是“面向连续缺失评价的有限预算参数优化，以及分模态约束的低成本通道筛选”。没有证据声称新发明DE/BPSO或首次提出两阶段优化；也不声称顺序调参和选特征等于联合全局最优。

DE未优于随机搜索、过滤最优子集未能迁移到B模型、子集在联合缺失时明显退化、完整性能超出保底阈值、维度减少但时延不降，均是必须如实记录的失败或限制。最终保留通过valid规则的模型，负结果仍能说明本题哪些优化有效、哪些不值得投入。
