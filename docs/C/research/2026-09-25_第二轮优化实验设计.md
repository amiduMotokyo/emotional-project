# C第二轮优化实验设计：受约束的预测集成搜索

日期：2026-09-25。状态：用户已授权完整实施，执行器与数值检查已实现；运行进度见[启动指南](../experiments/第二轮优化实验启动指南.md)。配套[设计参数清单](../../../C/configs/q2_round2_design.json)保留设计快照状态，实际运行状态单独归档，不能传给第一轮运行器执行。

实施前修订（尚未开始任何第二轮基础训练或valid评分时）：R7原定全部初始偏置为0会使DE的偏置坐标永远无法变化。改为前7个锚点偏置为0，后5个随机点的两维偏置用`default_rng(search_seed+100000)`独立采样U(-0.15,0.15)。共同权重初始化、12个初始点及300次总请求不变。此为算法可执行性修正，不是根据效果调参。

依据：[原文精读](2026-09-25_优化论文原文精读.md)、[第一轮实验与论文](../paper/第一轮智能优化实验论文草稿.md)。本轮继续由C负责智能优化与评估，复用B的融合模型及输入协议。所有阈值、预算和新增划分都是本轮预设，不是赛题要求或已经验证的最优设置。

## 1. 本轮要回答什么

**主问题：在同一个模型库、同一评价协议和相同搜索预算下，差分进化能否找到比等权、贪心和随机搜索更可靠的集成？对权重集中程度的约束是否有帮助？**

这样可以把昂贵的网络训练与廉价的优化器比较分开，并直接检查A方案带来的启发，而不是把A的66%左右成绩归因于某一个优化器。

研究假设预先区分：

- H1：模型库存在可利用的互补误差，等权集成优于固定单模型。
- H2：同预算DE优于随机权重搜索和贪心选择；仅优于单模型不支持H2。
- H3：抑制权重过度集中可以缩小拟合集与折外集的收益落差；惩罚更小不等于泛化更好。
- H4（消融）：类别偏置提供额外收益，但可能只改善ACC或改变类间权衡。

本轮主实验不同时更换编码器、融合结构、缺失增强或特征子集。短训排序诊断与任务感知特征选择保留为独立后续实验，见第9节。新动态神经集成器需要额外训练与调参，先不加入主比较，以免无法归因。

## 2. 先明确数据证据的边界

### 2.1 历史结果不是新的盲测

附件2仍为train 3395、valid 728、test 727，执行前核对实际数据清单。第一轮已查看test，且本轮设计受到历史结果启发，因此第二轮在同一test上的结果只能称为**锁定后复评**，不能宣称全新独立盲测或无偏确认。冻结协议后不再根据test修改权重、算法、阈值或提交选择。

附件1不追加训练；附件3/4无标签专项数据不进入搜索和统计。若没有新的合规标签数据，本轮如实保留自适应复用数据的局限，不虚构外部验证。

### 2.2 两种模型库用途不同

1. **历史库探索：** 可加载第一轮E0—E5权重及其预测，检查文件、协议、错误重合和计算成本。它们已用valid选检查点/配置；在同一valid上再做集成交叉验证，不能消除这些历史依赖。只用于工程准备与描述性分析，不作为本轮折外收益主证据。
2. **第二轮模型库：** 只在官方train内做基础模型训练和检查点选择，基础模型训练阶段不读取valid/test指标。然后对valid生成训练外预测，供集成层拟合与折外评价。超参数族仍参考了历史经验，所以只能称新训练下的内部验证，不称全流程无偏评估。

### 2.3 新库的划分与检查点

- 将官方train按约90%/10%分成`base_fit`与`base_stop`，仅用于本轮新库；实际人数由分组与分层结果决定，记录清单，不硬编码近似数。
- 若有可靠原始视频/主体分组ID，优先同组不跨分区，在可行范围保持类别比例；没有ID时使用固定随机种子的类别分层行级划分，并明确没有主体隔离保证。不得将`train:i`当视频ID。
- 标准化、类别权重仅在`base_fit`拟合；固定缺失视图分别为fit/stop生成，不能直接混用基于全部train统计的旧缓存。
- 每模型训练18轮，每轮只在`base_stop`的四场景计算S，按与第一轮相同的best-checkpoint规则选模型。不用valid决定epoch。所有模型相同规则。
- 缓存视图必须通过显式样本ID关联；划分子集后不得重新编号导致`ViewDataset`读取错位。
- 锁定集成后不再把`base_stop`加入基础训练重训，否则模型预测分布发生变化，已拟合集成权重不再对应同一模型库。

## 3. 固定模型库与输入协议

继续使用C第一轮384维MiniLM输入路线：人工文本缺失先替换词元再编码，音频74维、视觉35维。保留B的`robust_gate`、双头输出、恒定学习率、batch 64、类别加权CE与SmoothL1。训练缺失概率0.8、8组视图、模态组合与比例沿用第一轮。mask_seed=20260924。

**每个库6个模型：3个预先给定学习率×2个训练种子。**

| 参数族 | learning_rate | weight_decay | dropout | lambda_reg |
|---|---:|---:|---:|---:|
| L | 0.0004 | 0.01 | 0.25 | 0.8 |
| D | 0.0008 | 0.01 | 0.25 | 0.8 |
| H | 0.0016 | 0.01 | 0.25 | 0.8 |

该范围是围绕现有默认值的对称倍数变化，不称为最优参数搜索。模型全特征，固定维度。库A种子为20261001、20261002，库B为20261003、20261004；种子只是整数，不表示实验安排日期。两个库使用相同fit/stop划分，仅训练随机性不同。

库A为预先指定的最终候选库，库B用于重复性检查，不按结果从两个库里挑更好的提交。即使发现6模型高度相关，也保留这个负结果，不看valid后追加隐藏维度或更多模型“直到集成有效”。若一个模型OOM、非有限或损坏，停止该库比较，修复后用新版本统一重建受影响部分，不暗中替换成员。

A的768维预计算文本与编码后遮挡路线仅列为背景结果，不能直接混入此库比较缺失鲁棒性。另行复现A必须单独列协议；主实验不承诺追平其66%ACC。

## 4. 搜索对象与目标

对样本i、场景s、模型m缓存分类概率`p_mis∈R³`及回归输出`r_mis∈[-3,3]`。仅使用验证标签拟合集成层，不重复运行编码器或网络。

静态权重`w_m≥0，Σw_m=1`，两头共享权重：

`p_is = Σ_m w_m p_mis`，`r_is = Σ_m w_m r_mis`。

分类取argmax；主目标使用raw回归，不做符号修正。四场景为完整、T/A/V分别中段30%缺失，沿用第一轮：

`S = mean_s(MacroF1_s − 0.15 MAE_s + 0.05 Pearson_s)`。

S是项目选择指标，不是官方评分公式。固定三类全集计算Macro-F1；常量预测Pearson沿用记0的选模回退，同时输出常量标志。ACC、逐类F1单列，不能把ACC最好等同于S最好。

**集中度惩罚：** 对M=6，定义`C(w)=(MΣw_m²−1)/(M−1)`，均匀权重为0，单模型为1。正则DE最大化`J=S−0.01C(w)`。0.01仅为预注册系数，不由外层折成绩选择；无正则组是λ=0消融。本轮不扫描λ。该惩罚是项目设计，不是声称复现Neural Ensemblers的模型dropout或其定理。

**偏置消融：** 固定中性类偏置为0，负/正类偏置各在[-0.15,0.15]中搜索。`p'_c=softmax(log(max(p_c,1e−8))+b_c)`；回归头不变，权重惩罚仍计算于w。偏置作用于对数概率，不是直接把常数加在概率上。推理时定义与训练时完全一致。

## 5. 集成层折外评价与公平对照

### 5.1 交叉拟合流程

在valid上固定3折，按样本ID/真实分组ID划分。**同一条样本在所有缺失场景中的副本必须进入同一折。** 每折只用另外两折拟合搜索器，用留出折评价；不允许根据留出折调整搜索预算、正则系数、种子或停止点。

各样本收集一次折外预测，再在完整728条折外预测上逐场景计算S，避免小折Macro-F1的简单平均与全体指标混淆。同时展示各折结果用于诊断，不能把3折当作3个独立数据集。参数的最终选择使用折外结果，所以该结果仍是内部模型选择成绩，不作为独立确认检验。

**不是把同一权重在三份样本上打分再平均。** 后者没有重新拟合，且对于某些指标接近原目标，不能叫交叉验证防过拟合。这里每折搜索所得权重必须独立保存。

### 5.2 实验组

| ID | 方法 | 主要比较 |
|---|---|---|
| R0 | 固定默认单模型：D参数族、各库第一个种子 | 与第一轮结构一致的新训练基线 |
| R1 | 仅用折内拟合集选择6个模型中的单最佳 | 检验集成是否超出选单模型 |
| R2 | 6模型等权 | H1；没有权重拟合成本 |
| R3 | 有放回贪心选择，保存拟合目标最好的历史集成 | 简单强基线 |
| R4 | 随机权重搜索，最大化S | 与DE同预算 |
| R5 | DE权重搜索，最大化S | R5对R4/R3检验H2 |
| R6 | DE权重搜索，最大化S−0.01C(w) | R6对R5检验H3 |
| R7 | R6加两维类别偏置 | R7对R6检验H4 |

R0不能因本轮重新划分训练数据而直接与第一轮E0做算法因果比较；主要比较全部在同一新库内完成。

### 5.3 搜索预算

- R4—R7每次搜索300次目标请求；初始12个：等权、6个单模型顶点、5个随机权重；随机权重由6个独立U(0,1)坐标归一化生成，不混用Dirichlet与归一化均匀分布。
- DE采用已有DE/rand/1/bin机制，种群12，24代，初始12+24×12=300；F=CR=0.5，上一代快照更新，越界裁剪。搜索坐标u∈[0,1]^6，w=u/Σu；全零向量回退等权。此编码存在尺度冗余，记录为实现限制，不称为新的DE算法。
- R4使用同样12个初始权重，另采288个；R5/R6相同搜索种子、初始点及变异规则，仅目标有差异。R7初始权重相同；前7个锚点偏置为0，后5个随机点的偏置独立均匀采样（见实施前修订），后续联合搜索8维。
- R3运行50步，每步试加6个模型，共300次请求；允许重复模型形成次数权重，返回折内目标最好的历史点，并列固定最小模型ID。其空间不同，属于同请求预算比较，不声称搜索分布相同。
- 重复请求计入预算；缓存命中、独特权重数、实际目标调用、CPU墙钟时间分别记录。不可把一个调用含多个场景/样本的差异隐去。
- 随机方法各运行优化器种子11、23、37。**一个方法的固定输出是三次搜索所产生的概率和回归预测的算术平均**，不在留出折选“最幸运种子”；R7必须平均预测，不能把bias平均当作等价操作。无偏置时等价于平均权重。R3为公平预算重复3次确定性搜索，900次总请求，允许缓存并如实计时；报告它实际上只有一条独特轨迹。

除惩罚和偏置消融外，训练库、缺失视图、指标和预算都固定。输出拟合集与折外集的ΔS，检查“更会拟合验证标签”是否真的变成可迁移收益。

## 6. 选型、成功标准与停止条件

先完成库A、B全部折外比较，再应用以下预设规则，不按test决定：

1. 相对各库R0，候选的clean Macro-F1下降不超过0.01，clean MAE增加不超过0.02；两个库都需通过。限制比第一轮更紧，但仅适用于本轮同库比较，不追溯修改旧结论。
2. 要称有实际增益，候选相对R0的两库平均ΔS至少0.005，且任一库ΔS不得为负。这是预设实用阈值，不是统计显著性结论。
3. 同时报告相对R1、R2、R3、R4的差值。DE只超过R0而未超过简单集成，不支持“DE优越”；R6只有相对R5改善才支持正则设计；R7只有ACC升、S降时只记录指标权衡。
4. 满足条件者按两库平均折外S排序；与最佳差不超过0.002时优先实际非零模型数更少者，再按R0→R1→R2→R3→R4→R5→R6→R7顺序选择。没有方法满足新增收益条件时，保留现有第一轮已锁定提交模型，本轮报告负结果。
5. 最终候选只在库A上，以全部valid、相同预算及相同种子聚合规则重拟合集成层。禁止按全部valid拟合成绩重新换方法。

有效模型数同时报告`1/Σw²`，但它不等于推理成本。只要权重非零就仍需相应基模型推理；不在看到结果后设阈值裁掉小权重。共享输入编码的缓存成本、6模型前向成本与后处理成本分别计时。

完整64条件面板（clean+63缺失）在方法锁定后用于valid压力测试和test复评，报告raw/coherent两个固定版本；不能按其结果重选方法。若发现数值/掩码实现错误则废止受影响运行，修复并记录版本，而不是选择另一个分数更好的结果。

统计报告：两库分别成绩、平均差、三个搜索种子的分散程度；搜索种子不冒充网络训练重复。可以对折外预测按样本或真实视频簇做2000次配对bootstrap，所有场景同抽样；区间只反映已拟合模型的样本不确定性，不覆盖重新搜索、重新建库及方案选择的不确定性，不使用强显著性措辞。

## 7. 预算与实施顺序

| 阶段 | 必要工作 | 预算/产物 |
|---|---|---|
| P0 协议检查 | 核验输入、ID、划分、历史缓存可用性；测计时 | 无新训练；`protocol_manifest.json`、清单、预计成本 |
| P1 新建两库 | 3学习率×2种子×2库；18轮上限 | 12次训练，共216 epoch；每轮含stop验证 |
| P2 预测缓存 | 两库6模型，各valid四场景；不读取test标签 | 概率/回归/ID/场景与模型哈希 |
| P3 集成比较 | 两库×3折×R3—R7×3搜索×300 | 27000次目标请求；R0—R2另计少量评估 |
| P4 锁定与重拟合 | 库A最终方法在全部valid拟合 | 若是搜索方法，最多900次目标请求 |
| P5 锁定后评估 | 新候选及固定R0/R2参照的64场景复评 | 独立计编码、前向、评估时间；不更新选型 |
| P6 交付 | 配置、权重引用、折外预测、表格、失败记录 | 有真实结果后再更新实验论文 |

复用旧训练结果不抵扣本轮新库216轮；旧模型只用于P0探索。训练预算不包含文本视图编码、64场景推理、bootstrap或打包成本，不能只用216轮宣称总成本。

运行前用P0及第一个完整模型的实际耗时估算总时长；首模型属于正式预算，不多加pilot训练。无提前设定GPU小时数时只报告预测耗时，不假定用户有无限资源。若资源不足，预设缩减为仅库A：108epoch、13500次搜索请求，并明确只能得到单库初步证据，不能满足两库稳定增益的正式标准。不得看算法排名后只给某组追加预算。

共享GPU默认串行训练，避免争抢显存。首次完整训练若成本或学习曲线说明18轮规则不合适，冻结修改后的统一协议再重建全部受影响模型；不得只改某一参数族。

## 9. 两项后续专项实验（不计入主预算）

### 9.1 短训排名诊断

先从第一轮已有history抽取同一配置同一种子的`best≤6`、`terminal6`、`best≤18`、`terminal18`，报告与最终best规则的Spearman及top-k重合。只对实际训练到18轮的配置比较，并说明它们包含晋级筛选偏差，不能把这个相关性当整个搜索空间的可靠性。

若后续重新做HPO，独立预抽12配置×2训练种子、全部训练18轮，比较四种规则；216×2=432额外epoch，不免费包含在主实验。两种搜索器必须共享初始点、评价规则和预算，配置选择不因test反馈改变。暂不直接移植FastBO：18轮下曲线点少，论文的拟合及排序论证不足以保证此处有效。

### 9.2 任务感知特征选择

固定默认参数，独立比较全特征、既有BPSO过滤选择、STG、SAND；声学/视觉配额仍为37/18和56/27，文本保留。不与集成权重优化同时改，避免收益归因混杂。

SAND需明确归一化、噪声仅施加于可观测位置、全时间共享通道、推理top-k及训练轮数；STG需处理λ与实际选择数的匹配，不能只声称“同稀疏度”而不核对。学习门与普通正则化噪声需要消融；更长训练的成本计入。该分支尚未指定完整预算及执行器，不属于本次可启动主实验，也不预设优于BPSO。

## 10. 本轮允许写出的结论

可写的候选贡献是：统一连续缺失输入协议下，比较固定模型库上的等预算集成搜索，并检验权重正则化及偏置的折外收益。它是应用方法设计，不是首次发明DE、集成选择或正则化。

无论结果是否提升，都须区分：基础模型差异、普通集成收益、优化器贡献、权重正则贡献和类别偏置贡献。设计不预设可达准确率，也不把A的分数设成不同协议下的必达目标；实际结果另行归档，避免改写预设假设。
