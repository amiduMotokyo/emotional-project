## 1. 研究问题与可证伪假设

在相同输入编码、融合模型、更新步数和评估缺失掩码下，用训练阶段测得的缺失难度持续更新情景采样，能否优于均匀连续缺失训练？

- H1：自适应采样提高固定、等权缺失评估面板的平均表现，而非只提高训练时经常采样的情景。
- H2：持续更新优于预热后固定概率；若不成立，采用更简单的固定策略，并如实报告。
- H3：收益不以明显牺牲完整输入性能为代价。预设完整输入 macro-F1 下降容忍值为 0.01、MAE 上升容忍值为 0.02；它们是项目接受阈值，不是显著性阈值。

“高损失”可能来自不可恢复信息或标注歧义，因此不假设越困难越值得无限增加训练。均匀混合、概率平滑和完整输入保留用于限制此问题。

## 2. 数据边界与启动条件

- 使用附件2既有 train/valid/test；按已有数据记录分别为 3395/728/727 条，接入时重新核对真实文件、ID与标签。训练统计、难度探测和标准化拟合只用 train。

- 不加入问题1的100条特征，不引入额外情感数据集。
- 首轮使用对齐版；输入编码与特征版本在所有实验组间固定，未对齐版不是本轮必做实验。
- B 必须先解决附件3只有 `text_bert` 没有预计算 `text` 的差异。拟优先采用匹配词表的冻结文本编码器，并保持附件2/3同一路线；是否可缓存、在哪一层施加缺失，须由真实输入验证后锁定。
- 人工缺失不能只在模型已充分读取完整内容后才模拟，却声称等价于原始文本丢失。若选择编码后特征置零，应明确研究的是该层特征不可用，并披露上下文编码可能保留信息的限制。
- 不能从完整 raw_text 重新编码来恢复专项集本来缺失的信息；不能把原始 `text_bert` 中的零、PAD、attention mask 机械当成统一的人工缺失标记。

正式运行门槛：真实批次可读；标签映射正确；已说明有效/填充/缺失掩码来源；一次前向与反向有限；保存加载后可复现预测；附件3最小样本可走同一输入流程。上述事项目前均待实现验证。

## 3. 模型和共同训练设置

复用 B/src 中同一个双任务融合模型，输出三分类 logits 和情感强度；各组拥有独立权重。固定三分类映射 0负、1中、2正；分类采用 argmax，不用回归预测是否恰好等于0判断中性。

共同任务损失起点：

`ℓ(x,y)=CE(logits,y_class)+|prediction−y_reg|/3`。

除以3是固定尺度约定；各组使用同一损失与回归输出规则，不再根据情景乘难度损失权重。若 B 的输出层或损失需要调整，先在 valid 上确定共同设置，再重跑所有比较组，避免把骨干差异归因于采样。

预设 batch size 32、最多20个 epoch、预热3个 epoch。优化器、学习率和冻结策略继承 B 的统一基线并记录；不能在未测量时编造最优配置。暂不做大网格搜索。固定轮数训练并从相同验证面板选 checkpoint，正式对照不使用各组不同的提前停止步数。

训练样本每轮打乱遍历一次，不通过重采样情绪类别改变标签分布。缺失训练组每个样本以0.2概率保留原始输入，以0.8概率选择一种连续缺失情景；各组概率相同。这里“完整输入”指未额外施加人工缺失，不保证原数据无噪声或原始无效位置。

## 4. 缺失情景与生成器

情景 `g=(S,r,b)`：

| 变量 | 预设取值 | 含义 |
|---|---|---|
| S | T、A、V、TA、TV、AV、TAV | 哪些模态发生局部缺失；不是删除整个模态 |
| r | 0.2、0.4、0.6 | 相对于各被选模态可遮挡有效位置数的目标连续长度比例 |
| b | 0、1、2 | 所有合法连续起点按顺序分成前、中、后三段 |

总计63种缺失情景，另设完整输入。训练情景不从附件3统计推断。多模态共享归一化起点随机数与目标比例，但分别映射到自己的合法起点；若位置集合不同，不声称各模态对应同一物理时段。

### 4.1 精确定义与边界

对于选定模态，设可遮挡有效位置数为 L，最长连续有效段长度为 R。排除 PAD、已知原始无效位置以及有依据的特殊词元；不把分离有效位置拼接成虚假的连续时间轴。

1. L≥2 时，`k=min(max(1,floor(rL+0.5)),L−1,R)`。至少保留一个可用位置，避免退化成整模态缺失。
2. 枚举原序列上所有长度 k、每个位置都有效的连续窗口，按起点升序得到列表 A。不能跨越原始无效孔洞。
3. 抽取 `u~Uniform(b/3,(b+1)/3)`，取 `A[min(floor(u·len(A)),len(A)−1)]`，整行特征置零。短序列的不同组可能映射到相同窗口，必须记录重复和实际缺失比例，不伪称不同处理。
4. L<2 时该模态不可生成局部缺失。对样本仅在可实现 S 的情景集合内重新归一化概率；完全无可实现情景的样本保留原始输入、记录原因。原样本不删除。
5. 评估时不可实现情景保留输入并标记退化，主表保留全部样本；另报告可实施样本子集与覆盖率。各模型必须使用完全相同的覆盖集合。若退化比例明显，正式运行前调整协议并统一版本，而非事后挑选样本。

记录 `sample_id, scenario_id, modality, start, stop_exclusive, requested_rate, actual_rate, eligible_length, mask_seed, fallback_reason`。位置单位为特征索引/归一化序列位置，不换算为秒。

### 4.2 掩码语义

至少区分：序列 padding 掩码、原始有效掩码、此次人工缺失掩码、最终 observed 掩码。训练生成器知道人工缺失位置，不代表专项推理拥有相同真值；正式模型输入掩码只能使用推理时可得到的信息。若依赖估计掩码，评估也使用相同估计过程，真值掩码仅供统计。禁止向自适应组额外提供其他组没有的掩码或情景编号。

## 5. 难度估计与采样更新

### 5.1 用相同模型测量配对损失差

不直接使用采样训练批次的原始高损失：它会混入样本固有难度、模型 dropout 与自适应采样选择偏差。每轮结束后，使用当前模型 `eval + no_grad` 在固定规则的训练探测面板上计算：

`d(i,g,e)=clip(ℓ(f_e(mask_g(x_i)),y_i)−ℓ(f_e(x_i),y_i),0,2)`。

这里只截断调度难度，不截断正常训练损失；不对 d 求梯度。不引入冻结教师，因此只能称为同模型配对难度代理，不能宣称完全消除样本难度。

探测面板起点：从 train 按三类分层、固定随机种子选192条（每类64条；不足则取该类全部并记录），它们仍参与普通训练。每轮按预先固定的轮换规则取每类4条，共12条，用这同一批样本评估所有63种情景，便于配对比较。有效覆盖不足的组不得伪填数值；先按类内求均值，再对有样本的类别等权，并记录类别覆盖。

每轮最多新增12次完整样本前向和756次缺失样本前向，按批次执行；不是新增756个训练步骤。冻结编码器的可复用部分只有在不改变缺失语义时才能缓存。所有成本均计入实测时间。

探测随机流与训练/valid/test掩码随机流独立。所有方法、同一种子共享相同探测ID、轮换、人工掩码与时间点。探测不更新参数、BatchNorm统计或优化器状态。

### 5.2 组级平滑与有界概率

设当前组平均难度为 `D_g(e)`，首次有效观测直接初始化 `H_g`，之后：

`H_g(e)=0.8 H_g(e−1)+0.2 D_g(e)`。

当某轮没有有效观测时保留旧 H；从未观测的组使用所有已观测组均值，若全无观测则使用0。记录有效计数，不把缺数据当作难度为零。

对缺失情景定义：

`z_g=H_g/(max_h H_h+1e−8)`，

`q_g=exp(z_g/0.5)/Σ_h exp(z_h/0.5)`，

`p_g(e+1)=0.5/63+0.5 q_g`。

预热前3轮均匀采样，从第4轮开始使用第3轮结束时得到的分布；之后每轮更新。完整输入的0.2概率不参与这63组的归一化。

由于 z 在[0,1]且温度为0.5，softmax 概率比最多为 exp(2)；均匀混合还进一步限制集中程度，每组至少得到0.5/63的条件概率。全零难度退回均匀分布。仍需记录熵、最小/最大概率和实际采样频数，避免将不可恢复情景长期当作唯一训练重点。

这里有意改变训练情景分布，不用 `1/p_g` 重要性校正，否则会抵消优化重点。**评估始终按预先指定情景等权统计，不按训练概率加权。**

### 5.3 训练流程伪代码

```text
固定共享初始化、数据顺序和各用途随机流
p = uniform(63)
for epoch in 1..20:
    遍历训练样本：20%保持原始输入，80%按p采样可实施的连续缺失
    只优化共同双任务损失
    关闭dropout及梯度，计算训练探测面板配对难度，更新EMA
    下一轮p = uniform / 第3轮末固定分布 / 当前EMA分布（取决于实验组）
    在固定valid面板上评估并按预注册规则保存checkpoint
恢复候选checkpoint；冻结协议后运行完整test面板
```

本轮不加入一致性损失，不做每个训练样本的多个困难窗口搜索。

## 6. 实验矩阵与结论边界

| ID | 方法 | 设置 | 回答的问题 |
|---|---|---|---|
| E0 | 普通训练 | 不额外生成缺失；同一模型和训练轮数 | 缺失增强整体是否有用 |
| E1 | 均匀连续缺失 | 0.2完整＋0.8均匀63组 | 主基线 |
| E2 | 预热后固定采样 | 前3轮同E1；第3轮结束算p并固定 | 固定的难度分配是否已足够 |
| E3 | 在线自适应采样 | 前3轮同E1；之后逐轮更新p | 主方向 |

E2是本项目固定采样对照，不叫 CMAD 复现：没有其教师、CAFD或加权损失。E1/E2/E3使用同一初始化与前3轮训练轨迹，可保存共享预热 checkpoint 后分叉；优化器与随机状态一并保存。后续差异限定在情景选择策略。

为核对成本，核心对照 E1/E2/E3 都运行同样的探测前向，但只有相应组使用结果更新概率；同时单独报告 E1 关闭探测时的自然运行成本，避免掩盖主方法的额外开销。E0不必做无用探测。记录相同更新步数与实际 GPU 时间，不把等步数称作严格等算力。

第一轮 seeds=[17]，共4条训练轨迹。主对比 E1/E3补 seeds=[29,43]，总计8条轨迹（可复用每个种子的共同预热）；E0/E2单种子结果只能作初步机制证据。如要声称在线稳定优于固定，E2也补两种子，总计10条轨迹。

仅在核心结果完成且预算充足时增加一个消融：E3-raw，使用截断缺失损失而非完整/缺失差，保留相同探测成本。若未做此消融，不宣称难度差设计已被独立验证。

## 7. 评估、模型选择与公平性

### 7.1 固定验证面板

每轮 valid 评估完整输入＋9个单模态情景：S∈{T,A,V}、r∈{0.2,0.4,0.6}，起点从所有合法位置均匀选择；掩码按 ID 固定并落盘。9组权重相等，与训练概率无关。这样避免每轮做完整63组的高成本评估。

统一 checkpoint 分数（仅项目约定）：

`J=0.5[(1−F1_clean)+MAE_clean/3]+0.5[(1−mean_g F1_g)+mean_g MAE_g/3]`。

选择 J 最小的 epoch；相同分数取较早 epoch。F1为三类macro-F1，分数范围[0,1]。所有组相同。模型与调度参数冻结前，可用完整 valid 63组复核多模态缺失性能，但不得新增大量试验后仍称为预注册单次验证。

### 7.2 最终独立评估

在协议锁定后的附件2 test 上，对每个选定模型评估完整输入＋63组。每组使用2套固定掩码种子101/202，所有训练种子和方法共享。先分别计算每套掩码的指标，再在掩码间平均；不将复制同一样本的掩码版本当作独立样本夸大置信度。

主报告：63组等权平均macro-F1与MAE，同时提供 Accuracy、weighted-F1和Pearson。完整输入单列。报告按模态组合、长度、位置的分层结果，以及最差组F1/MAE；最差组在每个模型上可能不同，另列各组差值便于比较。

分类固定三类，未预测到某类时其F1按0处理；无真实标签样本不参与指标计算。NaN/Inf视为失败，禁止静默丢弃。Pearson在预测或真值为常量、样本不足时记为NA并报告有效组数，不强填0；跨组只报告有效组均值与覆盖率。

### 7.3 可选泛化压力测试

核心实验完成后，增加未参与训练和选参的 r=0.3、0.5（T/A/V，固定中段）、r=0.8的高缺失压力测试，或多模态异步位置测试；单独报告，不并入主面板。它们只是新缺失条件，不是新数据集。首轮不增加多个缺口、整模态删除等另一套训练任务。

### 7.4 随机性与结论规则

- E1/E3报告三个训练种子的均值、标准差和逐种子配对差，掩码种子不能替代训练种子。
- 主方向获支持的预设条件：等权缺失macro-F1均值提高、MAE均值降低；三个种子至少两个同向；完整输入变化在第1节容忍范围内。未满足时按“权衡/不支持/待更多验证”报告，不挑指标宣称全面提升。
- 若做区间估计，按 video_id 聚类进行配对重采样；先合并同一片段的掩码结果，避免把同源片段或同片段多掩码当作独立证据。三种子的稳定性与抽样区间分别解释。
- 单独报告E3相对E2，缺少重复时只称初步趋势。若E2与E3相当，应优先部署成本较低且更简单的有效方案。
- 只读这三篇不足以完成新颖性检索；最终贡献写为赛题场景中的方法适配和实证改进。

## 8. 时间与计算预算

沿用三天计划，不增加新的方法路线。当前日期不能说明当天还剩多少工时，以下是剩余工作量安排，不是已测耗时。

| 阶段 | 目标 | 退出条件 |
|---|---|---|
| 第一天剩余时间 | 生成器、评估、调度器、B接口接入；测一次完整epoch含探测和验证 | 缺失边界测试通过，真实数据训练与专项输入能走通 |
| 第二天前半 | E0—E3单种子筛查，排除实现错误 | 有可追溯指标、耗时和采样日志 |
| 第二天后半 | E1/E3补种子；预算允许时补E2 | 核心比较完成，停止新增配置 |
| 第三天 | 锁定模型、附件3预测、图表、论文和复现打包 | 保留足够人工核验时间 |

先测 `t_train`（每epoch训练）、`t_probe`（难度探测）、`t_valid`（10个验证条件）、`t_test`（最终完整面板）。预算按各轨迹分别累加 `epochs×(t_train+t_probe+t_valid)`，再加最终评估、编码缓存、失败重跑余量；不能只算训练前向。

例如，若实测包含探测/验证的epoch为2分钟，8条20轮轨迹约需5小时20分，尚未包括最终评估；若为5分钟，则约13小时20分。此处只是算术示例，不是该机器的实测预测。共享预热可节约一些时间，但不能依赖这一点掩盖最坏预算。

正式实验前先做3轮计时，排除首轮加载/预热影响。若预算超限，优先取消可选压力测试和消融、减少完整评估掩码重复；必要时把所有方法统一缩短到10轮/预热2轮，版本升级后重跑比较，不在看到某组好坏后单独给它增加训练。最低交付仍保留E0/E1/E3；若E2未完成，不作“在线优于固定”的结论。

|---|---|---|
| B 数据接口 | 唯一ID、三模态张量、标签、各类掩码及来源；对齐版目标形状B×50×768/74/35 | 附件2与附件3能进入同一编码和预测通路 |
| B 模型 | 三分类logits B×3、强度B；统一forward、保存/加载、train/eval行为 | 无标签也可推理，输入缺失不导致NaN；不依赖情景标签 |
| C 生成器 | 根据有效区间生成局部连续缺失，返回副本/掩码和元数据 | 不改原始数据、不把PAD当缺失、不发生整模态误删 |
| C 调度器 | 预热状态、每组EMA/计数/概率、随机状态与序列化 | 概率有效、可断点恢复、日志可追溯 |
| C 评估器 | 固定标签口径、面板、ID对齐和汇总 | B可复用；无测试标签泄漏 |

编码器配置和有效掩码尚未交接，是正式训练的实际阻塞项。C可先用构造张量完成生成器、调度器和评估器，再接入B唯一实现；不复制另一套数据加载和基础融合模型。接口变动同步B调用方。
