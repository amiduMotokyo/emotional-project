# A的工作文档

| 目录 | 内容 |
|---|---|
| requirements/ | 需求理解、修改建议、任务拆解与接口需求 |
| research/ | 创新点、文献调研、方案比较和待验证假设 |
| experiments/ | 实验配置说明、结果分析、消融与错误归因 |
| paper/ | 本人负责的论文正文、公式和排版材料 |

新文档按用途放入以上目录。长期保留的配图可放在对应目录下的assets/并使用相对链接。原始日志、模型权重与缓存放在根目录A/outputs/。

需求变更应区分赛题要求与个人建议；涉及全组的已确定结论同步到[公共协作约定](../项目结构与协作约定.md)。写作进度按[三天计划](../三天模块分工与论文写作计划.md)执行。
