# 问题三：解释输入与交付接口

## 数据边界

模型仅由附件2 `train` 学习；附件2 `valid` 的标签用于选 checkpoint、校准类别偏置和评价，不参与反向传播。附件4的20条样本无标签，仅做最终预测与解释；未对齐特征和原视频只用于把解释位置映射回可查看的证据。不得计算附件4的ACC。

每条附件4对齐样本的 `text_bert` 形状为 `(3,50)`（第0行 token ID、第1行 attention mask），`audio` 为 `(50,74)`，`vision` 为 `(50,35)`。原文、对齐文件、未对齐文件与视频按两位 `id` 配对，要求四者一致。模型内部文本编码为 `(50,384)`，音视频仅对有效位置用训练集统计量标准化并裁剪至 `[-5,5]`。有效掩码遵循训练时定义，零填充位置不可计入贡献。

## 解释接口

`Q3Predictor.predict` 输出 `predicted_polarity`、`predicted_intensity`、三类概率、原始/类别偏置后logit及门控权重。主模型是现有 `Fusion`，解释模块不增加可训练参数。

对原预测类别 `c` 保持固定，模态作用定义为 `Δ_m = z_c(x) - z_c(x\setminus m)`，其中 `z` 已包含验证集确定的类别偏置。删除文本时先把相应原 token ID 换为 `[UNK]`（ID 100），重新调用 ONNX 文本编码器，并清除文本有效掩码；音视频清除相应有效掩码并把标准化特征置零。三模态作用绝对占比 `|Δ_m| / Σ_j |Δ_j|`，但负的 `Δ` 表示该模态抑制当前预测。主要参考模态优先取最大正 `Δ`，没有正值时取绝对作用最大者并显式标志。门控权重是内部诊断，不能冒充贡献。

局部证据对每个有效对齐位置做单点删除，记录有符号logit下降及正值归一化分布；再穷举宽度1–3的有效位置窗口，以联合删除的真实logit下降选择关键片段。文本位置经相同 MiniLM tokenizer 的 ID 一致性检查后映射到原文字符区间；音频、视觉位置由 `A/src/evidence_locator.py` 与附件4未对齐特征逐向量匹配，再按音频20 Hz、视觉15 Hz估计原媒体时间，并以视频/音频流时长核查。时刻属于近似定位；精确性仅针对“对齐向量匹配到未对齐向量”。无法匹配时输出状态，不填造证据。

## 输出

- `attachment4_predictions_explanations.csv`：20条全量预测、强度、概率、三模态 `Δlogit`/概率变化/作用占比/门控、主要模态及主要证据位置，可直接作为汇总表。
- `attachment4_explanations.json`：三模态全部单点分布和局部窗口、完整定位状态与媒体信息。
- `cards/01.md`–`cards/20.md`：逐样本解释卡；`frames/` 与 `audio/` 是原媒体证据预览。
- `validation_predictions.csv`、`validation_summary.json`：728条有标签验证样本的逐条结果和评价。
- `plots/`：混淆矩阵、模态比较、20条测试样本作用占比和典型样本局部分布。

数值可复现以 [配置](../../../B/configs/q3_explain_20260925.json)、[运行脚本](../../../B/scripts/run_q3.py) 与随包 checkpoint 为准。`run_report.json`记录实际包路径、类别偏置和验证指标。
