# 第二题：文献融合方法对比实验

状态：已完成旧流程口径下两种训练设置的对比；每个设置跑3个随机种子。负责人：B（M4架构比较），复用C维护的缺失掩码与指标定义。

代码：[模型实现](../../../B/src/literature.py)、[统一运行脚本](../../../B/scripts/run_literature_models.py)。逐种子完整记录和27种缺失条件指标保存在 `B/outputs/q2_literature_models_old_protocol/` 与 `B/outputs/q2_literature_models_old_protocol_clean/`；模型权重保存在服务器对应输出目录的 `checkpoints/` 下。`B/outputs/` 按项目约定不纳入Git，仓库保留本实验说明与汇总表。

## 为什么补跑旧流程

第一轮架构摸底使用了服务器的 `cache_qint8`、30轮上限和5轮早停，与项目之前报告的全精度缓存结果不是同一次实验口径。现在改用服务器现存的旧 `cache`，按旧流程的损失、优化器、训练轮数和验证集选模规则，分别复跑无缺失增强和连续缺失鲁棒两种设置。只读取附件2的 `train.npz`、`valid.npz`；不使用附件3或test划分。

## 实验设置

数据为附件2对齐版，训练3395条、验证728条。缓存使用此前的MiniLM编码结果，音频74维、视觉35维；音视频标准化参数只用训练集有效位置拟合。分类标签为Negative/Neutral/Positive，连续目标为情感强度。

两种设置都使用类别加权交叉熵 + 0.8×SmoothL1、AdamW（学习率8e-4、权重衰减0.01）、批次64、最多35轮、早停耐心7、梯度裁剪1.0。无增强设置只用原始有效位置，并按完整验证集的 Macro-F1 − 0.15×MAE + 0.05×Pearson 选模；鲁棒设置以0.8概率进行连续缺失增强，随机缺失1至3种模态、缺失率从10%/20%/30%/50%抽取，并按“完整输入 + 三种模态各缺失中间30%”的平均分选模。每个架构、每种设置均用种子20260924、20260925、20260926训练。

实验在服务器RTX 2080 Ti（11GB）、PyTorch 2.7.0+cu126、NumPy 2.2.5环境中运行；缓存中的MiniLM逐位置表示为float16存储。实际命令如下，唯一差别是是否启用连续缺失增强：

```bash
python -u B/scripts/run_literature_models.py \
  --cache /mnt/disk/data/inainai/mosei_e_20260924/cache \
  --output /mnt/disk/data/inainai/mosei_e_20260924/literature_runs_legacy_20260924 \
  --device cuda --seeds 20260924 20260925 20260926 \
  --epochs 35 --patience 7 --batch-size 64 --robust

python -u B/scripts/run_literature_models.py \
  --cache /mnt/disk/data/inainai/mosei_e_20260924/cache \
  --output /mnt/disk/data/inainai/mosei_e_20260924/literature_runs_legacy_clean_20260924 \
  --device cuda --seeds 20260924 20260925 20260926 \
  --epochs 35 --patience 7 --batch-size 64 --no-robust
```

## 与此前报告结果的关系

项目原先的全精度单次验证结果是：无增强融合基线 Accuracy 0.6126、Macro-F1 0.5831、MAE 0.6115、Pearson 0.6399；连续缺失鲁棒模型是0.6209、0.5969、0.6121、0.6368。它们在[基线实验记录](q2_fusion_baseline.md)中。它们是单次训练结果；本报告另外给出三种子均值，不能将两者误认为同一模型checkpoint。本轮鲁棒门控基线三个种子的Macro-F1为0.5959/0.5834/0.5826，MAE为0.6100/0.6240/0.6551，说明单次值会受到种子影响；旧报告0.5969接近本轮最高种子，但高于三种子均值。

按新旧两种训练设置分别看：无增强时，MAG-MiniLM适配版的三种子Macro-F1为0.5935，高于本轮重训门控基线0.5898，也高于此前单次无增强基线0.5831；但MAE和Pearson较差，且Macro-F1仍低于此前连续缺失鲁棒模型0.5969。加入缺失增强后，四种文献方法都没有超过此前鲁棒模型的Macro-F1；Pearson则存在模型间取舍，例如鲁棒版MISA为0.6394，高于此前鲁棒模型的0.6368。

## 方法实现与局限

- **LMF**：对三个注意力池化后的64维模态向量加入常数项，使用秩8低秩因子化融合。[Liu等，ACL 2018](https://aclanthology.org/P18-1209/)
- **MISA**：各模态进入共享/私有子空间，以CMD对齐共享表示，并加入差异约束和重建损失，权重为0.3/0.1/1.0。[Hazarika等，2020](https://arxiv.org/abs/2005.03545)
- **MulT**：采用六个方向的跨模态注意力及模态内自注意力。当前输入是已对齐的50步序列，所以这是MulT式注意力的适配，不是原论文未对齐设置的逐项复现。[Tsai等，ACL 2019](https://aclanthology.org/P19-1656/)
- **MAG-MiniLM适配版**：用音视频特征生成有范数约束的偏移并注入冻结的MiniLM词元状态。没有端到端微调BERT/XLNet，因此不应称作完整MAG-BERT。[Rahman等，ACL 2020](https://aclanthology.org/2020.acl-main.214/)

LMF、MISA和MAG返回的接口权重是各模态有效比例，不是学习得到的贡献度；跨模型比较只使用分类与回归指标。所有指标来自验证集，三种子数量有限，且验证集参与选模，不能视为独立测试成绩。首轮 `cache_qint8` 摸底结果仍留在 `B/outputs/q2_literature_models/`，不用于本报告的主结论。
