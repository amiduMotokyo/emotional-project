## 实验对象与可复现性

沿用当前最佳、已校准的问题二交付候选：`all-MiniLM-L6-v2` 顶部两层微调 + `Fusion`，seed 20260925，第3轮 checkpoint；负/中/正logit偏置 `[0.2,0,0]`。包位于服务器 `/mnt/disk/data/inainai/mosei_e_20260924/q2_minilm_deploy_candidate_calibrated_20260925/`。验证集参与模型选择和校准，因此下述验证成绩是**已用于选择的同一验证集**成绩，不能当作外部独立泛化估计；附件4没有标签。解释是模型固定后进行的输入遮挡，无额外训练。

原始附件4审计结果：对齐、未对齐与视频各20条，ID/原文一致；20条 tokenizer token ID 与原文重新编码完全一致。音频、视觉对齐向量可在未对齐特征里逐向量检索；按20 Hz/15 Hz得到的时间与媒体流时长相符。样本13视觉无有效位置，故无视觉关键帧；样本16未对齐 `vision_lengths=1` 与40个非零帧不符，定位使用实际非零特征及精确向量匹配，并在结果里保留这一数据质量限制。视频时间是估计值，不应称为精确帧标注。

## 错误归因与限制

中性召回率只有34.78%，且文本效应占比、主模态数量均显示当前模型明显偏向文本。验证集的模态切片说明多模态输入并未自动带来均衡利用；中性→正性错误、47条高置信错误和部分样本的分散局部作用，应在论文里明确作为失败类型。输入遮挡衡量的是**这套模型在这一遮挡协议下的敏感性**，模态间可能相互作用，三个 `Δ` 既不满足加和性也不是因果贡献；`|Δ|` 占比只为可读性归一化。局部音视频时刻依赖名义采样率，能定位媒体片段但不保证逐帧精度。

运行环境：PyTorch 2.7.0+cu126、NumPy 2.2.5、Transformers 4.51.3、scikit-learn 1.6.1、ONNX Runtime 1.20.1、FFmpeg/ffprobe 4.3。预测在CPU执行，文本ONNX逐条推理，以保持与已选交付模型一致。可视化由 Matplotlib 生成，命令见 [B说明](../../../B/README.md)。
